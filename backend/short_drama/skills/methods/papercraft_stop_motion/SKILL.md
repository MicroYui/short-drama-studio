# 纸艺定格讲解

## 用途

适合纸艺定格讲解项目，把学习目标、纸艺隐喻、布景、镜头、旁白与声音组织成片。

## 输入

讲解主题、关键事实、纸艺与定格风格要求、目标时长、声音及参考素材。

## 方法

- 将信息分解为可通过纸艺物件和动作说明的段落。
- 用一致的材质、物件关系与定格动作承接镜头。
- 讲解和画面按真实时间组织，完成后检查声音、字幕与镜头连续性。

这是“知识讲解 + 纸艺定格制作”的成套项目适配器。该上游方法未覆盖的独立教学论证责任应明确记录为能力缺口；不得用本地仿写 Skill 冒充覆盖。与其他上游 Skill 组合时也只保留一套学习目标、内容结构和镜头计划。

## 交付

纸艺定格讲解方案、镜头与动作设计、资产引用和视频结果。

## 检查

核对信息准确、纸艺物件关系清楚、动作连贯及视听对应。

## 来源与加载

上游 Markdown 及 `meta.yaml` 按固定版本保存；运行时只把当前角色需要的原文章节加载为参考。本文件仅负责映射现有工件和 Tool 边界。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_h3/original/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
