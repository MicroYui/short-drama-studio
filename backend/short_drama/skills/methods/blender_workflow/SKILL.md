# Blender 建模与动画

## 用途

为可编辑三维模型、场景、动画和机位设计提供制作方法；实际操作需要 Blender 场景连接。

## 输入

模型或场景需求、尺寸与参考、已有工程、目标镜头或动画以及输出规格。

## 方法

- 工程与可执行能力。
- 建模方法。
- 动画与渲染。
- 保存与检查。

[专业方法章节](references/production-method.md)按当前角色与阶段加载。用户已经明确的目标、风格和决定直接沿用；只在用户指定的确认点停下。

## 交付

当前可完成的制作方案与建模说明；接通软件后交付可编辑工程及对应渲染。

## 执行条件

- Blender 与可读写目标场景的执行接口；当前产品未内置该连接器。

## 检查

核对本次要求、实际文件和可观察结果；只报告已经完成的内容，保留可用素材与无关修改。
