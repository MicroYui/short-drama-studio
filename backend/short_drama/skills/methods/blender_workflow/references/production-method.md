# Blender 建模与动画：专业方法

## 工程与可执行能力

只有用户明确选择 Blender、要求 .blend 或续改相关工程时才采用软件工作流。先读取目标工程路径、场景、对象、相机和未保存状态；窗口打开不等于场景接口可用。

本方法不安装软件或连接器。当前目录没有 Blender 工具时，可整理尺寸、建模步骤和相机方案，明确尚未执行；不得虚构脚本调用或已保存文件。接通工具后只修改当前任务对象，不重置无关场景。

## 建模方法

从参考提取轮廓、主结构、单位、厚度、截面、对称、连接和重复关系。单图看不见的背面与内部结构作为假设，不伪造精密尺寸。

连续曲面优先考虑曲线、放样或连续网格；不要用独立方块拼出本应连续的弧面。重复结构可用 Array 或实例，切削可用 Boolean，圆角可用 Bevel；依据当前软件和对象实际支持情况选用。先做大比例和连接，再做倒角、材质与微细节。

检查物体局部轴、缩放与法线。车轮轴与行进方向垂直，接触部件应相接；只看一个角度合理不能证明空间结构正确。

## 动画与渲染

区分物体运动、摄影机运动和材质变化。设定镜头起止、观察目标、运动曲线、帧范围与实际帧率，检查轨迹中间状态，避免穿模、突然翻转或焦点漂移。

渲染前读回活动相机、输出格式、尺寸和路径。静态交付不额外制作动画；动态交付需要可播放的完整运动预览。源工程、渲染帧与最终媒体分别组织，临时帧不逐张导入项目资产。

## 保存与检查

核对多角度轮廓、连接、材质与阴影；动画在正常速度下检查。保存目标 .blend 并确认文件真实存在及外部依赖可读，预览对应本次保存的工程。

只将用户需要的已生成图片或视频通过 artifact.import_local_version 等真实工具登记；工程可以保存其实际路径，不能说成项目原生可编辑三维对象。断连后先回读状态，避免重复建模或重复启动渲染。
