# 可选角色卡与布局参考

MiniMax Design 的双区三视图模板是可复用的版式方案，原始出处保留在 sources。当前项目按需要选择清楚单视图、已有角色卡、参考布局生成或本地拼板；没有规定每个人物都要双区卡或必须导入远程 guide。明确选中且可用的 DRAFT 图片可以直接服务当前镜头。

## 按用途选择版式

已有图片清楚提供当前需要的身份和姿态时直接复用。需要在有限参考图数量中表达多个视角时，可以组合正脸、正面、侧面、背面；不要求不相关的视角先完成。判断重点是同一身份、服饰与比例稳定、必要细节可读，而非固定分区比例。

若选择参考模板辅助生成，可登记真实可读的 URL 为 AssetVersion：`https://cdn.hailuoai.com/public_assets/opencode/character-sheet-layouts/drama-character-sheet-three-view-20260701.png`。通过 `artifact.import_url_version` 导入后，将其在 `ordered_references` 中声明为 `LAYOUT_GUIDE/GUIDE_ONLY`；用户人物图声明为 `SUBJECT_IDENTITY/AUTHORITATIVE`。最终引用顺序对应实际发送图片，只有确实发送的 guide 才能在 Prompt 中标注为布局依据。布局图只贡献位置和版式，不贡献其中的人脸、年龄、体型、服饰或风格。

远程模板不可读时可省略它、使用现有图或选择本地拼板，重新编号真实参考，不围绕 CDN 反复重试。无需固定像素位置时，一图生成可以描述需要的视图，不将无 guide 的结果冒称使用过官方模板，也不因此禁止生成。

当下游要按固定区域裁切、要求准确 16:9 双区几何或统一背景色时，用可用的正脸近景、正面全身、所需侧面及背面精确版本调用 `image.compose_reference_sheet`。`DRAMA_CHARACTER_DUAL_ZONE_16_9` 可作为该次选择的 layout_profile；按实际用途设置 show_labels、background_color、target_size。Tool 根据语义槽合成，不依赖概率生成精确分区，输出继续保留真实状态与来源。

侧面方向只有在单侧疤痕、耳饰、非对称服饰或具体机位需要时才影响可用性。不能仅因 LEFT/RIGHT 枚举名或轻微中性背景差异就要求返修。拼板后需看是否因为裁切或缩小丢失了身份细节，不能把本地几何准确等同于素材语义正确。

正常失败例：角色脸清楚、视角齐全，但左区比计划略宽。无需固定裁切时可直接使用；确需准确区域时改用本地拼板，避免为几像素版式重新抽脸。

## 定向修复与重复载体

已有身份只需修服装、视角、裁切或局部状态时，保留精确当前版本作为身份输入；同一对象可用 EDIT，外部身份图可用 REFERENCE_GENERATE。无参考 GENERATE 适合从零建立身份，不适合要求保持原人物的定向修改。

多个同规格标牌或文件载体仅文案不同时，可复用一件可干净裁用的物理母版，由本地复制/组装和独立 TEXT_PLATE 承担准确文字。不是所有道具都需要先制作无字母版；已有准确素材符合用途即可直接采用。

正常失败例：一张牌的外形可用但价格错误，先判断能否用对应时窗的图版遮盖；若本地编辑无法满足真实透视/遮挡需求，明确缺口，而非宣称已有视频局部重绘能力。
