# 短剧与连续剧的本地制作方法

以下内容整理自 manifest 标明的 MiniMax Design 短剧工作流。保留故事、摄影、表演和资产连续性的经验，执行对象是当前项目的剧本、镜头、所选素材与剪辑；原文留在 sources 供溯源。

## 镜头语言与情绪

先明确这次镜头让观众知道什么、站在哪个人物的处境里、发生什么变化，再选择景别和运动。全景适合建立距离、位置、环境压力或孤独；近景让选择、识别和反应可读；过肩、主观镜头和双人镜头可以说明关系。需要人物同时行动时，保持一个可读的关系镜头往往比频繁切脸更清楚。特写用于重要信息或情绪转折，避免每次说话都切极近景。

为关键节拍确定观众要读到的证据：是物件被交出、某人认出了什么，还是听者的态度改变。证据必须在构图、遮挡、景别和停留中可见；“画面里有这个物件”不等于观众能够识别它。背景人物只承担本镜需要的关系和反应，后面才参与的人可以由后续机位引入，不为交代全体身份把开场挤成合照。

声画可以分工。台词继续时可以看听者的反应，画外的脚步或一声招呼可以让新人物进入有依据，动作切点可以省略没有戏剧作用的归位操作。保留当前角色与发声者的明确归属，不能把叙述段直接转成旁白，也不能让镜头中的听者代说画外对白。沉默、日常环境声或动作声可以留出观众理解反转的时间，不必每个空隙都被解释或配乐填满。

景别数量和切点由情节、表演和素材决定，不按每组固定配额。眼平较中性，高低角度可以改变主观强弱关系；缓推可以集中压力，固定镜头可以让尴尬或犹豫持续，手持可以表现失衡。运镜要有明确起点、路径、速度变化、终点和与动作的关系；简单动作无需同时加入推、摇、环绕和变焦。

焦距、景深、快门与镜头质感是描述可见效果的手段。说明需要压缩空间、扩大近远差异、分离背景、保留环境关系还是呈现清晰/拖影运动；只有确有用途时写数值，不将电影机型号、色彩曲线或镜头参数当作生成模型一定能精确模拟的物理设置。参考构图可贡献机位与空间，不能改变人物身份。

光向、光质、反差、色温和时辰共同建立气氛，同一连续动作保持光源方向和环境基础一致。窗光、顶光、逆光和实景灯优先符合空间逻辑；柔光可以缓和表情，硬影可以强调分裂或压迫，但不要求每盏灯都承担象征意义。夜景要保留脸、手和关键物体的可读层次。

正常失败例：审问段每句都换一次仰俯角，人物位置越来越不清楚。先恢复一个稳定关系镜头，只在权力变化时改变景别；不因没有集齐景别就补拍。另例：写了长串摄影机参数，成片人物却看不清，优先改人物与背景的明度关系和构图，而非继续堆型号。

## 表演与物理动作

把情绪写成观众能看到的选择与变化，如想离开时重心转移，却为等待答案停下脚步。只细化影响理解的触发、接触和收束，避免堆叠眉眼手肩的微动作或每步停住。FACS 如 AU4 眉下压只是可选沟通，不替代外观描述，也不要求模型精确测量肌肉。

说话角色、原对白和轮次与剧本一致；需要强调时说明语气、停顿和听者反应，不借编译偷偷重写台词。动作与对白可以并行，避免要求人物在极短时窗同时完成取物、转身、走位、长句对白和复杂反应。关键反应需要可见的建立时间，微表演是否读得到由景别和实际素材决定，不机械规定每个动作的毫秒数。

表演指令先写人物在做什么来影响对方，再选身体细节。例如“想装作不在意，却必须听到答案”可以表现为拿起包准备离开、脚没有移动、等对方说完才收紧提带；若只堆眉、眼、肩、呼吸的代码，表演容易成为与人物目标无关的动作清单。保留一个有意义的可见变化，比每个部位都动更容易形成可信的反应。

对时长做一次可表演的推演：逐字对白自然读出，不可同时完成的动作按先后占用时间，接收信息后的反应留出可读的停顿。不把2.8秒强塞成输入金额、刷卡、确认、挂卡、双手端盘、转身并接住新人物反应的全过程；如果叙事只需要“支付成功后离开”，可以用付款结果与端盘离开的切接，保留真正触发转折的下一次反应。需要完整过程的故事则给它足够覆盖和时长，而非删除关键因果。

纸面时间不能证明节奏成立。难判断的段落可用已有静帧或分镜图、临时演读和当前时间线做简单连续预览，观察信息是否看懂、反应是否过早切走、铺垫与回报间距是否合适；缺图时也能先用文字占位检验配时。把临时图声标作节奏预览，实际生成后再按真实对白、动作与可用剪点调整，不把预览当成最终成片验收或每组强制门槛。

身体遵守重量、支撑和惯性。拿杯子要有手接触杯柄/杯身、物体离开桌面、持握后的关系；递物要说明谁持有、谁接触、何时交接。衣物和头发随身体运动，不强制固定延迟；复杂触碰可以减少同一时窗的主体和动作，必要时拆到连续的前后镜。

正常失败例：人物仍在托盘时两只手同时取卡，或手已经伸到胸前但后镜又从盘边开始。检查实际取用片段的手部状态，保留可用表演，只改对应衔接或受影响生成组。静帧能确认可见手位，不能证明台词、声线和嘴型已经同步。

## 空间与状态连续性

先建立人物与场景锚点：左右关系、相对距离、面向、视线对象、门窗/柜台/桌子等稳定地标和关键道具位置。对话正反打保持轴线和互补的屏幕视线；确实跨轴时用观众看得懂的走位、过渡机位或重新建立空间来解释。不能只复述“不越轴”而没有人物在哪侧、看向哪侧的具体关系。

同场跨镜保留与叙事有关的持物、承重、容器内容、座位和进出关系；改变须有动作或可信省略支持。手别在当前方案与已采用片段间要连续，但不是用户指定时，导演可连同受影响镜头调整，不能让局部工单把它误标为不可改事实。状态设计不要求每步生成静帧；实际边界从采用片段的使用区间读取，不能用设计终态冒充已拍事实。

复核以当前范围为单位。画面左和人物左手分开表达；局部特写失去身体方位时标明不确定，不凭反打直接断言左右手。跨镜检查需要双方实际采用来源和区间，缺一侧时只给可验证的单镜判断。

正常失败例：建立镜中甲在左乙在右，两张近景都朝画右看，拼接后像各说各话。优先调整其中一张的机位/视线或采用已有可用反打；若没有足够素材则只重制受影响组。又如菜盘分格和食物数发生变化，先判断是否影响剧情证据，不为无关桌面摆件触发全片返工。

## 资产规划

先按当前剧本或镜头的真实需求列人物、场景、道具和声音对象。角色可记录年龄感、体型、脸部与发型识别点、服装层次、职业/时代线索、常见姿态和本场状态；只写可用来保持身份或服务表演的信息，不自动臆造背景故事。选角图明确是身份、服装还是风格参考，多人同组时分别写清各图对应谁，防止配角的突出脸部覆盖主角。

时代与身份一致性重点检查服饰结构、器物、建筑、文字载体和行为习惯是否与项目设定相容；风格化和有意混搭以用户设定为准。服装常态与湿、破、脏等剧情状态可以共用同一人物身份，只有实际需要时创建派生状态图。

场景描述包括可用空间、入口/出口、主活动面、地标、尺度、材质、时段和主要光源。优先选择与镜头机位、动作接触和人物比例相容的现有素材，不为所有场景强制生成四向卡。近景只需要部分场景信息时，不扩展无关区域。

道具按识别与互动需要锚定；普通陈设随场景提供。完整/破损、空/已装物、封闭/打开是剧情状态，不自动各建一图，更不把抬手、初触、松手逐拍列为素材。先判断哪些可由现有参考与动作指令表达，缺少必要可见证据才从可用版本派生。

当前明确选中且文件可用的 DRAFT 媒体可直接进入当前任务。先复用用户原图、已有单视图或合适角色卡；只有身份、必要角度、接触构图或 Provider 输入确实不足时补图。角色卡、多视图、布局 guide 和本地拼板都是用途驱动的可选策略，不作为视频准备的前置仪式。

正常失败例：为了短暂背景同学补齐全身四视图，主角反而缺一张清楚脸部。先满足当前镜头识别和动作需要；又如一张配角正脸在组里很突出，主角是复杂多格卡，应该精简引用并提高主角有效面部信息，而非默认增加更多角色图。

## 资产制作

按工作项需要生成、导入、派生或本地处理实际媒体。人物定向修改保留精确身份参考，说明这次只改服装、视角或状态；场景图说明机位与动作空间；互动道具说明大小、朝向、持握面和接触用途。风格参考只影响色光材质，布局参考只影响构图，不能让模板中的人物替代指定角色。

输入排序与真实送出的媒体一一对应，重复文件不因多个用途重复发送。图像数量限制以当前 Provider 为准，仅计算实际生成用途；准确字卡、价牌、字幕和屏幕叠字的剪辑图版独立保存，不挤占无关的生成图名额。当前图已经可用时，登记实际文件及用途即可，不重新生成仅为改变审核状态。

角色参考按所需视图组合，固定版式用本地拼板，不为无关分区差异付费返修。动作构图先解决人与接触面的关系；一张可信初态能提供依据时，不倒推再正推一串微状态照片。若修复可替代表现不断引入新漂移，保留正确媒体和明确缺项交回方案负责人；不能把已有缺陷当通过，也不需要重建身份与空间。

正常失败例：只修侧脸时重新无参考生成人物，发型和脸型一起变了。保持原图作为身份输入，定向修正缺项；图像 Provider 持续阻止必要素材时，说明具体缺图、用途与参考顺序，接受用户补图并继续其他就绪工作，不循环碰运气。

## 资产检查

检查实际候选是否完成当前工作项用途：身份、服装状态、必要视图、场景比例、手与道具接触、关键形制和可读性。多角色参考分别比对主要识别点，不能仅凭同款校服或大色块认定同一人。看不清脸、小物体或背面时记录该项未观察，已有文字描述不是图像已满足的证据。

先说明缺陷对指定用途的影响。非关键纹理或无关视图一般不阻断；身份、关键道具结构、受力和结果状态错误不能用“软参考”放过。构图参考与精确边界图的配准要求不同；若严格中间态只来自 Agent 方案，记录当前不满足并建议负责人比较局部修复与调整覆盖，保留可用部分。DRAFT 可明确选用，但拒绝、失效、缺文件或用途不匹配的媒体仍不可直接使用。

正常失败例：候选双区卡左侧略宽，但主角脸与各必要视图清晰，拒绝整张会引入不必要的人脸漂移。按实际下游用途决定直接复用或本地拼板。相反，背景学生脸很清楚却被误当成主角，属于实质身份问题，不能因图片已成功生成而通过。

## 当前范围验收

按本次目标检查当前文本、镜头或实际采用区间。剧本关注动机、信息、因果和对白；分镜关注叙事覆盖、表演可执行性、空间及状态承接；已有视频再检查可见动作、参考身份、实际配时和接触。只请求剧本时，不把未生成视频当作未完成。

区分设计意图、模型已生成、已下载可解码、抽帧观察、实际播放/听审和已采用。判断缺陷要给出具体镜号、时窗、参考和观众影响，按可用剪辑/局部字幕声音处理/受影响组新候选提出最小修复。没有观察音轨时，对白、声线、音画同步保持未知；不拿静帧或“有音轨”证明声音合格。

正常失败例：整组有多个预期切镜，按首镜时长判断全组超长，会导致无效返工。对照组内各镜实际覆盖与源区间，再决定裁剪或修复；技术回收成功但主角身份和对话轴线错误，则保留候选证据，不能宣称成片质量通过。
