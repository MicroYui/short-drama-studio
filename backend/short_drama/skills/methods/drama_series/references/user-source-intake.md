# 用户源图片的登记与人物锚定

- 用户消息中的附件、URL 和已存在的媒体是真实输入，必须保留并登记；不要求用户重复上传。收到素材后保留真实 AssetVersion、path 或 URL。原媒体始终是视觉依据，分析文字只负责分配用途，不替代原图。
- 一份图片可以贡献人物身份、服装妆发、场景空间、色光材质、构图光影或道具外形。用户已说明用途时直接采用；未说明时由 Agent 基于完整需求和实际媒体决定可贡献方面，不询问可从图像分析获得的可见事实，也不默认将它绑定所有镜头。
- 用户明确说某图就是主角或另一指定人物时，它是该人物的权威 identity reference。后续生成必须保留同一张脸、年龄感、肤色、发型和身体比例；风格参考、版式模板或其他人物不得贡献身份。
- 当用户原始图片已经是该稳定人物的完整角色卡，且实际包含清楚脸部与当前制作需要的正面、侧面、背面全身信息时，直接登记为当前唯一人物锚点。不重绘、翻新、裁切、加风格或生成第二张角色卡。
- 只有单张脸照、单角度人像、穿搭图或无法确认同一人多视角的图片，才作为 identity/wardrobe reference 生成新的标准角色卡。沿用用户明确指定的贡献，不从图片猜测未授权的人物经历、关系或剧情事实。
- 人物参考的顺序是：用户明确指定的 identity refs，然后是用户明确指定的 wardrobe/造型 refs。每个 slot 写清贡献，重复图片只传一次。未明确用途的上传图、搜索候选和氛围风格图不得偷偷成为人物身份参考。
