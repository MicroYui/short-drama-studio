# 音乐视频

## 用途

适合以最终主音乐为时间权威的 MV 项目，覆盖方向、音乐、制作计划、角色/场景锚点、分镜、H3 Prompt 和后期。

## 输入

主音轨或音乐创作需求、歌词与语言、时长、叙事意图、画面风格以及已有素材。

## 方法

- 确定主音轨及音乐结构，再安排对应段落的画面与叙事。
- 人物、场景和视觉母题跨镜头延续，镜头变化跟随音乐组织。
- 需要歌词或字幕时按真实音轨对齐；剪辑和声音围绕同一主音轨完成。

用户已给出的设定直接采用；用户明确要求确认某个工件时，只在该处暂停；其余流程若要求 Agent 自主完成，则由 Agent 语义判断未定选项并写入 trace。上游根 `workflow.md` 的进入信号不参与本系统路由；Leader 根据完整目标、已有音乐与工件自主选择本方法。

## 交付

音乐结构、视觉与叙事方案、分镜、参考资产、视频片段和音乐视频剪辑。

## 检查

核对主音轨来源、段落边界、歌词对齐与视听连续性，保留用户指定语言和音乐。

## 来源与加载

这是 MiniMax Design `mv` 完整项目工作流的薄适配器。运行时只按当前 Agent 角色装载上游原文整篇或精确章节，保留“最终主音乐是唯一时间权威”和逐阶段工件交接；不复制 Hub/Canvas 状态机，不覆盖本地 Tool Catalog 与 Provider Capability。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_design/3.0.11/workflows/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
