# MiniMax Design 广告 / TVC Workflow 适配

这是 MiniMax Design `ad-tvc` 完整项目工作流的薄适配器。运行时只按当前 Agent 角色装载上游原文章节，保留需求、风格、锚点、分镜、生成与后期的工件交接；具体 Category、Direction 与视觉技法由 Agent 结合项目语义按需选择，不在适配层建立题材关键词路由。

用户已给出的设定直接采用；用户明确要求确认某个工件时，只在该处暂停；其余流程若要求 Agent 自主完成，则由 Agent 语义判断未定选项并写入 trace。上游根 `workflow.md` 的进入信号只作为保存的原文，不是本 Harness 的路由规则。
