# 动态字体与视觉包装：专业方法

## 选择视觉载体

根据表达目的选择动态字体与空间卡片、主体追踪与拓扑图形，或实拍与二维手绘互动。可以组合，但需要一个主导关系；不要因用户说炫酷就添加所有技法。

字体可以承载信息、形成空间或响应动作；追踪图形可以解释运动和结构；手绘可以把人物情绪或作用力可视化。保持用户已有色彩、字体和人物方向，不套固定黑底、荧光或故障效果。

## 字体与追踪

文字写清出现原因、附着平面、尺寸层级、运动路径、遮挡、阅读停留和离场方式。让前景主体遮挡后方文字，匹配透视与焦点，避免所有文字平贴屏幕。

追踪框、关节线、轨迹和 ID 应跟随同一主体；节点不要跳到背景或互换身份。明确图形是创意包装还是实际测量；装饰数字不应冒充真实识别数据。精确标签用图版或编辑叠加。

## 手绘与实拍

每次互动明确触发、接触点、反馈和结果，例如手指触碰后粉笔线沿墙面延伸。手绘线条遵循载体材质、透视、遮挡和真实接触，保留人和物的身份。

同一物体的线条粗细、颜色、帧感与纹理应一致。可使用逐帧抖动、擦除、涂抹或纸张形变，但不以随机闪烁代替运动设计。

## 素材与编译

只为本次选中的路线准备主体、场景、布局、字体或动作参考。生成引用和后期图版分别标明用途，素材数量以实际请求支持范围为准；缺一类参考不代表必须把每类都补齐。

先写触发—主体反馈—图形反馈—相机响应—落稳的连续动作，再按当前路线编译。把准确文字与用户明确的声音要求原样保留；最终 Prompt 不加入另一套角色、模板或固定镜头数。

## 后期判断

正常播放检查图形是否真正解释或增强主体动作，去掉抢占阅读注意力的装饰。检查追踪漂移、穿帮、遮挡、文字精度和音效落点。需要实际跟踪、三维合成或逐帧修复而当前工具不支持时，说明需要的编辑能力，不能把生成式近似当精确跟踪。
