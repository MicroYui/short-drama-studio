# 产品界面与交互动效

## 用途

围绕真实界面和用户操作设计产品演示，以连续的交互、画面响应与镜头变化展示功能。

## 输入

真实界面截图或录屏、产品视觉规范、准确文字、要展示的用户动作及交付规格。

## 方法

- 产品视觉与事实。
- 交互因果与运镜。
- 节奏与可读性。
- 素材与视频编译。
- 验证与交付。

[专业方法章节](references/production-method.md)按当前角色与阶段加载。用户已经明确的目标、风格和决定直接沿用；只在用户指定的确认点停下。

## 交付

演示分镜、视觉图版、动态概念片或基于真实录屏的剪辑成片；明确实际使用的素材类型。

## 检查

核对本次要求、实际文件和可观察结果；只报告已经完成的内容，保留可用素材与无关修改。
