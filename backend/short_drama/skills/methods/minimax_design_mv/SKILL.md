# MiniMax Design MV Workflow 适配

这是 MiniMax Design `mv` 完整项目工作流的薄适配器。运行时只按当前 Agent 角色装载上游原文整篇或精确章节，保留“最终主音乐是唯一时间权威”和逐阶段工件交接；不复制 Hub/Canvas 状态机，不覆盖本地 Tool Catalog 与 Provider Capability。

用户已给出的设定直接采用；用户明确要求确认某个工件时，只在该处暂停；其余流程若要求 Agent 自主完成，则由 Agent 语义判断未定选项并写入 trace。上游根 `workflow.md` 的进入信号不参与本系统路由；Leader 根据完整目标、已有音乐与工件自主选择本方法。
