# 动漫与游戏宣传片

## 用途

围绕角色、战斗、剧情或世界观设计动漫和游戏宣传片，分别控制人物身份、画风、动作、文字及声音。

## 输入

角色设定、世界观、剧情或活动目标、参考素材、视觉方向、准确标题与声音。

## 方法

- 宣传重点与画风。
- 视觉分层。
- 动作与空间。
- 资产与视频。
- 声音与检查。

[专业方法章节](references/production-method.md)按当前角色与阶段加载。用户已经明确的目标、风格和决定直接沿用；只在用户指定的确认点停下。

## 交付

角色或世界观方案、分镜、主视觉、视频片段或宣传成片。

## 检查

核对本次要求、实际文件和可观察结果；只报告已经完成的内容，保留可用素材与无关修改。
