# 手绘与实拍融合

## 用途

适合手绘实拍融合的单场景创意短片，围绕真实接触、连续变形、逃跑路线与慢半拍追拍组织画面。

## 输入

创作目标、语言、实拍或手绘参考、期望的融合关系、时长和画幅。

## 方法

- 理解原始意图及语言约束，按本次需求设计具体创意。
- 明确实拍元素与手绘元素各自承担的内容及运动关系。
- 将画面、动作和融合方式编译为当前工具可用的输入。

这是单场景手绘实拍融合方法的项目适配器。它可以服务某个短片或某些镜头，但只有项目 Bible 明确采用时才影响更大范围的视觉表达，不能因 Skill 被选中就改写整部作品的 Style。

## 交付

融合创意、镜头或提示词描述，以及可用于后续制作的结果。

## 检查

核对语言、参考元素和融合方式，避免复用与当前目标无关的旧创意。

## 来源与加载

上游 Markdown 及 `meta.yaml` 按固定版本保存；运行时只把当前角色需要的原文章节加载为参考。本文件仅负责映射现有工件和 Tool 边界。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_h3/original/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
