# 广告与 TVC

## 用途

适合品牌广告、产品广告或剧情广告项目，覆盖需求简报、创意与风格、产品/模特/环境锚点、分镜、视频编译和后期。

## 输入

品牌与产品事实、传播目标、目标受众、时长与投放画幅、用户素材、已确认的创意和风格。

## 方法

- 先澄清事实与传播目标，再决定创意方向、故事表达和必要的视觉技法。
- 将产品、人物、环境及品牌元素登记为准确参考，按镜头需要使用。
- 镜头与声音服务同一传播意图，交付可继续剪辑的素材及成片。

用户已给出的设定直接采用；用户明确要求确认某个工件时，只在该处暂停；其余流程若要求 Agent 自主完成，则由 Agent 语义判断未定选项并写入 trace。上游根 `workflow.md` 的进入信号只作为保存的原文，不是本 Harness 的路由规则。

## 交付

创意与风格说明、产品/人物/环境参考、分镜、视频编译输入和后期结果。

## 检查

核对产品事实、品牌元素、镜头信息与声音表达；不把行业类别或视觉技法变成必选模板。

## 来源与加载

这是 MiniMax Design `ad-tvc` 完整项目工作流的薄适配器。运行时只按当前 Agent 角色装载上游原文章节，保留需求、风格、锚点、分镜、生成与后期的工件交接；具体 Category、Direction 与视觉技法由 Agent 结合项目语义按需选择，不在适配层建立题材关键词路由。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_design/3.0.11/workflows/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
