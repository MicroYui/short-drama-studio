# 广告与 TVC 的本地制作方法

## 简报与传播证明

先从用户目标和现有内容判断：观众应记住什么、相信什么、采取什么行动；产品在片中承担证明、解决问题、情绪连接还是品牌记忆。记录会影响画面的事实与限制：产品真实/概念身份、必须保留的文案、受众、语言、交付范围和用户素材用途。已有答案直接采用，只有无法合理推断且会改变结果的缺项才集中澄清。审美、镜头和节奏可由 Agent 根据目标自行决定。

每个核心价值对应“观众价值—可见动作—产品反应—结果”。产品静置、Logo 特写和旁白口播本身不证明功能。例：防水主张需要有依据的水接触与结果，不能用蓝色粒子替代；概念片可以表现设计意图，但不能把想象参数写成真实产品指标。

承接已有剧本或分镜时，保留用户指定的顺序、人物关系、表达结果和逐字文字；自主创作时选择能在现有时长与资源内执行的路线。用户要求备选才提供有实质差异的方案，不固定候选数量或增加选中标记后才允许下游工作的流程。

## 创意与风格判断

把传播目标落成具体视觉事件：初始处境、触发动作、产品参与、可见变化和收束。不同方案应改变事件或证明方式，而不只是换场景、色调和慢镜头。同一卖点可以由连续动作或多个镜头共同证明，避免重复解释同一事实挤占其他内容。

风格参考分解为色彩、光线、构图、景别、运动、材料、成像媒介和情绪。参考视频另记录有用时点、镜头长短关系、节奏变化和转场共同元素；没有实际观察时不伪造节拍和摄影事实。胶片颗粒、高光晕染、低保真数字噪点、扫描线都是按目标观感选择的手段，不机械叠加术语。

产品参考只贡献有依据的外形、结构、材质、标识和功能状态；风格参考按说明贡献光色与构图，不顺带复制陌生品牌、文字或人物身份。用户明确要求借鉴故事结构时，可在当前创作范围内采用结构并说明来源，而不是把所有参考一律降成配色。

正常失败例：路线看似不同但都是产品旋转加同一口号。回到传播证明，选择一个真实使用动作或冲突结果；不继续批量生成同构候选。

## 制作规划

从当前内容识别尚缺的创意、资产、分镜、视频和剪辑工作，按真实依赖安排，不预设完整串行阶段。已有可用素材和用户成稿直接进入对应工作；一个部件缺图不妨碍其他镜头继续。

分镜写清本镜传播作用、动作和结果、人物/产品位置、摄影意图、精确文字与声音时段。生成组按当前 Provider 能力兼容相邻镜头：总时长、场景状态、身份数量、实际参考、连续动作和对白容量均可承载才合组。请求使用本地实际配置，不向用户提供未接入模型选项。

全片时间与组内时间分别清楚记录，组内从零开始但不改原持续时长。对白或用户原文过长时先指出具体容量冲突，按自然停顿调整相关镜头；编译层负责标签和长度合同。不得凭短语估计就删掉必须保留的证明或对白。

需要旁白、同期对白、环境声、配乐或独立配音时按创作意图和当前可用 Tool 选择；不因上游工作流只支持原生音轨而排除本地声音能力。实际片段不足时保留任务/素材引用并交接明确缺项，不抄写私有计划协议或让 Agent 手运完整 Prompt。

正常失败例：全片已有十个可用镜头，只因一个产品特写缺图就重建整份计划。保持可用项，只补该特写和直接依赖。

## 镜头与视觉技法

先明确观众注意力落在谁、什么部件、什么动作，再选景别与运动。产品外形用能读轮廓的主视角，材质与机制用有来源的局部，使用结果用可见对比。摄影和文字各有层级；一次主动作完成后留出可读状态。

按事件选择技法，并写触发、变化过程、落点与检查目标：

| 技法方向 | 适用作用与可执行关系 |
| --- | --- |
| 色温弧、单点色彩 | 随处境变化调整冷暖或主色，保持产品真实颜色可辨 |
| 微距材质、轮廓光、聚光 | 用受光揭示表面和形体，说明光从哪里移动到哪里 |
| 物理动作卡点、匹配切 | 将开合、接触、转动或同一形状交给下一镜，有前后状态 |
| 信号故障、闪黑、冲击帧 | 为具体断裂、揭示或节奏变化服务，之后恢复可读画面 |
| 内外结构、几何变形 | 有产品依据时展示机构；概念变形写清连续轮廓和目标形态 |
| 感官母题、声波隐喻 | 让同一材质/形状跨环境、人物与产品转译，不伪造技术证明 |
| 字体构图、参数版面、品牌收束 | 使用准确文字、清楚层级、阅读停留和退出，不自动为每片添加 |

文字若进入空间，说明平面、透视、遮挡、运动与恢复；需要精确品牌图形/拼字时可以交给后期图版。字幕、包装和标识的职责按当前项目决定，不要求文字都由视频模型完成。

正常失败例：漂亮的液体转场改变了产品盖子形状。先简化转场或换成基于真实边缘的匹配切；产品身份比效果完整更关键。

## 资产规划

为本次镜头建立准确的用途映射：整体产品、部件、材质、UI/屏幕、Logo、内部结构、穿戴关系分别指向能证明它们的实际媒体。全景可复用整体图，细节镜头优先用真实细节图；校验资料不必全部加入生成参考。明确选中的当前可用 DRAFT 可以直接使用。

区分真实产品与概念产品：真实产品不为补齐版式编造未见角度、接口和标签；概念产品可按已定设计补充视角，并保留其概念属性。产品卡、主视觉卡和场景卡只在一致性确有缺口时制作，不按数量或固定版式建立前置条件。

人物与环境同样按画面需要规划。人物的年龄呈现、身形、服装、手部使用方式、动作熟练度和与其他人物的关系应符合当前设定；不要由旁白语言或地域自动推断人物身份。重复场景依地点和持续状态区分，机位改变不另建场景，A 到 B 再回 A 复用原 A。

正常失败例：把只用于风格的竞品海报当成产品正面，带入错误Logo。将真实产品身份与风格用途分开，保留正确媒体。

## 资产制作

每次生成/编辑说明主体、所需角度/部件、构图、受光、材料和每个参考的贡献。用户人物图锁定本人可见特征；穿戴商品同时参考真实产品的颜色、款式、Logo 位置与材质，保持人体与衣物的接触。

角色卡可按需要包含正脸、全身、动作或细节，不要求五区模板。身份辨认优先于排版；多名同装人物需要可区分的头脸、发型与体态，必要时采用清楚的单主体引用，避免次要人物的大脸参考压过主角的多视图小脸。

环境图明确入口、地标、尺度、材质与光源。如果视频需要一个连续空间，就让图像呈现可用空间；说明性宫格只作资料或拆出所需视图。真实文字、Logo 和像素级重复结构用现有文件与确定性组装，图像模型承担适合生成的部分。

正常失败例：产品整体图足够，但按钮特写糊。只补该部件；角色身份正确而卡片分区略有偏差，不以版式比例要求重做人物。

## 资产检查

按将要承担的用途检查真实文件：产品轮廓、比例、保护细节、结构和品牌图形；人物身份、服装、姿态与所需角度；环境地点、光位、地标和尺度。Logo 正确不等于所有功能已验证，整体好看不等于细节有证据。

多角色检查要逐一对应当前具体引用，避免只凭同色衣服判为同一人；多视图参考不能变成多人出镜。图片未涵盖的角度或功能保持未知，只对会影响本次镜头的缺口提出补充。

正常失败例：两位同装人物在近景交换发型，但校服颜色一致。应按各自头脸引用识别，不能凭服装相似就通过。

## 当前范围验收

对照当前传播目标与来源，检查卖点是否由实际画面证明、品牌和产品是否失真、动作是否完成、文字和声音是否清楚。区分视频可下载、技术可播放和内容适合采用，不把前两者当成质量通过。

缺陷落到具体时间与对象：错字/遮挡优先修图层或剪辑；产品身份漂移、错误机构或关键动作缺失可能需要该生成组的新候选。前者不要求重生成，后者保留已有素材并说明受影响范围。只能在实际听审或音频分析后判断旁白、对白和同步。

正常失败例：广告功能只有旁白声称，画面从未出现使用结果。补齐对应证明镜头或收窄文案，不用成功回收视频代替验收。
