# 当前项目的制作适配

## 视频编译

把当前角色的比例、材质、轮廓和表演风格写清，并保持项目选定的渲染语言。动作按预备、发力、接触、余势或回弹描述；夸张程度由角色和情绪决定。场景地标、光向、角色视线与道具位置从当前镜头和真实参考取得。

动画设计可使用挤压拉伸、跟随、节奏停顿和轮廓对比，让动作用简洁姿态读得懂。每个动作需要可见目标与结果，次级毛发、衣物或道具运动随主体发生。对白原文、人物声线和音效触发进入相应时窗。

正常失败例：人物提前做反应，物体随后才接触。明确接触帧前后的动作因果，并减少同窗内竞争动作。保持当前 H3 Provider 和唯一输出格式；本方法提供动画表演知识，不替换模型或强行改为某个品牌的默认画风。

## 后期判断

重点检查角色身份与轮廓、场景地标、动作接触、情绪回收和镜头意图。查看当前实际采用区间：预备动作是否保留，反应是否发生在触发之后，剪切是否误删余势或关键道具状态。

可用原声和对白优先保留，拟音与动作同步另据声音和时间证据判断。生成误带的分镜边框、箭头、时间标签与绑定标识需要定位处理；属于当前美术设计的手绘线、漫画分格或文字可以保留。

正常失败例：角色落地的脚步声比画面早。先移动或替换该条音效；角色身份持续漂移且无法用可用区间补救时，再生成受影响组。报告具体问题和修复位置，不为每个动画项目额外建立复盘文档。
