# 3D 动画短片

## 用途

适合明确采用 3D 动画制作范式的项目，覆盖角色/场景卡、镜头表、分镜、单镜与合成。

## 输入

动画短片目标、故事与角色设定、风格要求、镜头范围、已有角色/场景参考和可用生成能力。

## 方法

- 先明确动画表达及全局视觉风格，准备可复用角色与场景参考。
- 按镜头记录动作、表演、构图和连续性，支持逐镜提取与定向修订。
- 模型相关的输入格式交给对应 Provider 编译方法，完成后检查实际片段及整片。

这是 3D 动画制作方法的项目适配器，不是 `AI_SHORT_DRAMA`、`ANIME` 或其他格式的替代项。格式继续约束观看与叙事生产语境，本方法只在项目确实采用该 3D 路线时补充资产和镜头制作方法。

## 交付

动画角色/场景资料、镜头表、分镜、生成输入与可组接片段。

## 检查

核对角色和场景一致性、动作可读性、镜头衔接及合成结果。

## 来源与加载

上游 Markdown 及 `meta.yaml` 按固定版本保存；运行时只把当前角色需要的原文章节及参考译文加载为参考。本文件仅负责映射现有工件和 Tool 边界，不另写一套 3D 创作方法。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_h3/original/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
