# 纸张拼贴讲解

## 用途

适合纸张拼贴讲解项目，把观点或知识拆成拼贴隐喻、构图、镜头、字卡与声音。

## 输入

讲解内容、目标观众、来源事实、纸张拼贴风格要求、声音与时长约束。

## 方法

- 把需要解释的概念整理为清晰的信息顺序。
- 用拼贴元素、层次与画面运动承载信息，避免形式遮住重点。
- 保持讲解、画面和字幕的时间对应，按实际片段完成后期。

这是“内容讲解 + 纸张拼贴表达”的成套项目适配器。该上游方法未覆盖的独立教学论证责任应明确记录为能力缺口；不得用本地仿写 Skill 冒充覆盖。与其他上游 Skill 组合时也只保留一套内容结构、旁白和镜头计划。

## 交付

讲解与拼贴表达方案、分镜、元素引用及讲解视频结果。

## 检查

核对事实、信息顺序、拼贴表达的一致性和文字可读性。

## 来源与加载

上游 Markdown 及 `meta.yaml` 按固定版本保存；运行时只把当前角色需要的原文章节加载为参考。本文件仅负责映射现有工件和 Tool 边界。
