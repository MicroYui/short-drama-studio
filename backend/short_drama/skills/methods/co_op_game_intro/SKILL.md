# 双人游戏开场

## 用途

适合双人合作游戏的概念开场、角色化菜单动画和社交分享视频。

## 输入

游戏名称、两位玩家的信息、人物关系、目标风格和角色参考。

## 方法

- 让两位玩家的身份、位置、昵称与装备对应清楚，通过互动表现合作关系。
- 结合游戏主题安排构图、文字、按钮动效和事件节拍，让开场有明确的进入与落点。
- 用可读的姿态、接触和受光让人物融入同一画面，保留各自可辨认的特征。

制作时只读取与当前任务有关的知识和素材。Agent 根据本次目标自主安排工作，沿用你已经给出的设定和选择；你若要求某项内容先确认，就在那一处停下来。

已选且能满足用途的图片、视频和声音直接复用，需要补充时只制作缺少的部分。角色卡、多视图和参考排版按具体镜头需要选择。

## 交付

按本次目标提供开场创意、角色参考、画面设计、分镜或开场视频。

## 检查

检查双人身份和互动是否错配，文字是否清楚，画面次序是否完整。这里制作的是开场画面和动画；可操作的游戏菜单需要另行开发。
