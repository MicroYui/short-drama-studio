# 双人游戏开场

## 用途

适合明确制作双人合作游戏菜单开场的项目，覆盖人物身份、菜单首图、UI 文案与事件节拍。

## 输入

游戏主题、双人关系、开场目标、视觉风格、角色素材及当前视频 Provider 能力。

## 方法

- 依据用户意图选择视觉风格与双人开场的表达。
- 明确角色互动、构图和开场镜头，保留参考图的准确身份关系。
- 使用 H3 时加载确认图与视频提示词的专用片段；创作方法名称不绑定供应商。

这是双人合作游戏菜单开场的专项项目适配器。该上游方法已覆盖片头身份揭示和一次菜单交互；完整字体系统、真实多状态 UI 演示等额外目标若没有其他来源可核验的上游 Skill 覆盖，应明确记录为能力缺口，不本地补写方法。

## 交付

双人游戏开场设计、角色引用、确认图说明和视频生成输入。

## 检查

核对两名角色的身份、互动、画面次序与实际引用，避免角色或参考图错配。

## 来源与加载

上游 Markdown 及 `meta.yaml` 按固定版本保存；运行时只把当前角色需要的原文章节及参考译文加载为参考。本文件仅负责映射现有工件和 Tool 边界。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_h3/original/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
