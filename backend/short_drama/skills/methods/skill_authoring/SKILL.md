# 创作方法编写

## 用途

把可复用的制作经验整理成用途明确、按需读取的方法文档与角色章节；不会自动安装或修改运行代码。

## 输入

希望复用的任务、实际成功或失败记录、目标角色与已有方法。

## 方法

- 提炼有效方法。
- 入口与渐进读取。
- 本项目的文件合同。
- 验证与迭代。

[专业方法章节](references/production-method.md)按当前角色与阶段加载。用户已经明确的目标、风格和决定直接沿用；只在用户指定的确认点停下。

## 交付

可审阅的方法入口、必要参考、角色映射和验证建议；按实际完成范围报告。

## 执行条件

- 当前 Agent 可交付方法文档；安装或修改运行 Skill 文件需开发环境操作。

## 检查

核对本次要求、实际文件和可观察结果；只报告已经完成的内容，保留可用素材与无关修改。
