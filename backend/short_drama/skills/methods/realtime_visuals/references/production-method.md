# TouchDesigner 实时视觉：专业方法

## 输入与网络边界

用户明确选择 TouchDesigner 或编辑 TOE/TOX 时使用，泛称粒子、音画或交互不意味着已选择软件。区分真实时间、时间线、外部信号和离线导出，先说明本次产物。

操作前读取目标实例、工程、网络、输入和输出；当前没有控制接口时可分析网络方案，不能宣称已连接设备或已导出。摄像头、音频设备和网络发送使用实际授权及可用接口。

## 按数据类型设计

TOP 处理图像、纹理、反馈与合成；SOP 或当前支持的 POP 处理几何、粒子和实例；CHOP 处理通道、节奏、控制与触发；DAT 处理文本、表格、脚本与状态；COMP 组织模块与界面。三维渲染需要 Geometry、Camera、Light、MAT 与 Render 形成闭环。

先让输入—处理—输出成为最小可见网络，再增加反馈、实例或 shader。连续值先做范围与单位映射，再平滑；单次事件与连续控制分开。复杂分支保留可观察的中间输出和少量主控参数。

## 反馈与运行检查

反馈需要说明衰减、清除、分辨率和合成顺序，避免无限累积。节点参数、菜单值和表达式路径从当前软件读取，修改后检查实际值和节点错误，不凭旧版本记忆编造。

画面静止先查时间与显示，三维黑屏查渲染闭环，shader 错误查编译日志与输入，杂乱运动先固定种子并减少同时变化的参数。视觉 Viewer 不能证明音频已输出或设备已收到信号。

## 导出与交付

实时预览、文件录制和设备输出分别检查。核对实际编码、像素格式、时长、帧率与所需声道，硬件或许可证不支持的编码不能靠改文件扩展名解决。

保存可编辑网络和必要外部资源，按需导出组件。正常速度观察反馈与交互响应；只有真实文件可读、设备结果可确认时报告对应完成。断连后先回读当前网络，不重复初始化已存在的节点。
