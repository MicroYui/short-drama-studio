# 极简产品广告

## 用途

适合极简高质感产品广告项目，覆盖产品事实、锚定图、字卡、镜头与声音。

## 输入

产品事实、可用图片或视频、需要强调的特性、用户约束、时长及画幅。

## 方法

- 检查用户素材并提取可核实的产品事实。
- 围绕关键特性组织简洁的画面与信息，减少不服务传播的元素。
- 按现有素材和真实 Provider 能力安排生成、字幕及剪辑。

这是具体产品广告范式的项目适配器，不是所有商业视频的默认风格。与其他可核验的上游 Skill 共同使用时，每项方法应承担不同的目标、证据或工件，不重复同一套产品分析和分镜；创作者带货等未公开覆盖需求如实标记为能力缺口。

## 交付

产品事实摘要、广告画面与镜头方案、素材引用和制作结果。

## 检查

核对产品外观与事实一致、重点清楚；用户已给出的选择不重复询问。

## 来源与加载

上游 Markdown 及 `meta.yaml` 按固定版本保存；运行时只把当前角色需要的原文章节加载为参考。本文件仅负责映射现有工件和 Tool 边界。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_h3/original/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
