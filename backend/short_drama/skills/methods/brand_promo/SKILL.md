# 品牌宣传片

## 用途

适合品牌宣传项目，覆盖品牌事实、授权素材、受众承诺、镜头、声音、行动号召与交付检查。

## 输入

品牌事实、目标受众、传播诉求、可核实素材、时长及画幅要求。

## 方法

- 先整理品牌事实和素材来源，再选择适合本次传播的故事结构。
- 规划节拍、画面和动效语言，让每个镜头承担明确的信息或情绪作用。
- 按当前角色加载事实、素材、导演或交付检查片段，不把供应商当作创作类别。

这是上游品牌宣传方法的项目适配器，不是新的格式类型。与其他方法共同使用时，只承担该品牌宣传范式带来的独特判断和工件；不得重复创建另一份品牌事实、镜头计划或审片结论。

## 交付

品牌事实与素材清单、故事结构、节拍和镜头设计、生成输入及宣传片结果。

## 检查

核对事实有依据、素材用途清楚、画面与声音传达同一诉求；检查可见结果。

## 来源与加载

上游 Markdown 及 `meta.yaml` 按固定版本保存；运行时只把当前角色需要的原文章节加载为参考。本文件仅负责映射现有工件和 Tool 边界，不仿写品牌方法。

用途名称用于选择方法，不改变来源归属。原文与作者信息见[来源资料](../../sources/minimax_h3/original/)和 [manifest.json](manifest.json) 中的 `upstream_sources`。实际模型调用读取 manifest 指定的角色/阶段章节；本页是可读说明，不会整篇注入每个角色。
