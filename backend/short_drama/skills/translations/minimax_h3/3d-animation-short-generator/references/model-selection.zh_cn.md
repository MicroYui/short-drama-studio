# 视频模型选择与提示词塑形

## 步骤 7：视频模型选择卡 + 单镜头视频片段

### 视频模型选择卡（渲染任何片段前必需）

渲染任何片段之前，先展示视频模型选择卡。选择结果存储在 Project Brief 中，并在本项目的每个片段中复用，除非用户之后更改选择。

视频模型卡：

- **H3（默认推荐）**——擅长视觉包装、动态图形、清晰呈现文字/UI、多模态上下文理解以及成本效益（2K 下价格约为同级旗舰模型的 1/3，768P 下约为 1/2）。原生双通道音频。2K 下每个片段最长 15 秒。最适合：具有强烈设计语言、文字叠加、动态图形时刻、包装式转场的风格化 3D 动画短片，以及音频属于交付成果一部分的对白驱动节拍。
- **Seedance 2.0（高要求动画表演的回退选择）**——擅长电影化摄影、复杂镜头、富有弹性的皮克斯式表演以及由张力驱动的动作。最适合：追逐段落、肢体喜剧节拍，以及卖点在于动画表演本身而非包装的高潮镜头。
- **按镜头混用（高级）**——允许用户标记 `video_model: H3` 或 `video_model: Seedance2`，标记位置是各行的 `Shot Description` 列。当项目同时包含重包装镜头和重表演镜头时使用。未标记行默认使用 H3。

### 分辨率选择卡（视频模型之后）

视频模型确定后，展示分辨率选择卡：

- 768P（推荐用于 H3 首轮生成；成本较低）
- 2K（H3 默认质量；成本更高，最终渲染更清晰）
- 1080p（推荐用于 Seedance 2.0）
- 720p（Seedance 2.0 草稿；成本最低）
- 匹配项目 / 自定义分辨率

用户必须在首个片段渲染前确认分辨率。如果用户希望主打镜头拥有更高细节，之后可以逐片段更改分辨率。

### 单镜头片段渲染

对于每一行获批的表格内容，调用选定的视频模型生成对应的独立视频片段。每个片段都必须使用文本分镜文档中完全匹配的章节（如果该章节已被提取，则使用独立提取的节点；否则使用文档内章节），以及该行中的角色卡和场景卡。

所有视频模型通用的逐镜头规则：

- 将文本分镜文档作为每个镜头在叙事、构图、摄影机运动、动作调度、逐秒时序和镜头编号方面的权威参考。对于已提取为独立节点的镜头，改为读取提取后的节点。如果还存在铅笔分镜图，仅将其用于人工侧的姿势/剪影预检；不要让它覆盖文本分镜。
- 将角色卡作为身份信息的权威来源。
- 将场景卡作为环境信息的权威来源。
- **移除所有分镜双重绑定标签**（`[char:…]`、`[scene:…]`、`[shot:…]`、`[dur:…]`、`[hook:…]`）后再进行视频渲染——这些标签仅用于分镜参考，绝不能出现在最终片段中。铅笔分镜图还包含自身的镜头编号、摄影机图标、箭头和备注，这些内容也必须在渲染时移除。
- 已渲染片段只能包含干净、全彩、受皮克斯启发的 3D 动画内容。
- 不得包含分镜线稿、手绘草图纹理、标签、字幕（除非用户要求）或水印。
- 保持获批的画面尺寸/宽高比，以及分辨率选择卡中获批的视频分辨率。

### 针对模型的提示词塑形

文本分镜文档（或该镜头提取后的独立节点）会同时供两个模型使用，但包裹在分镜外层的提示词前缀有所不同：

- **H3 prompt prefix**（默认）：强调包装关键词、设计语言、动作清晰度、相关情况下的文字/UI 呈现，以及双通道音频意图。H3 的指令遵循能力很强，因此逐秒指令几乎可以原样发送。添加：`Pixar-inspired 3D cartoon rendering, C4D + Octane look, stylized Q-version proportions, warm SSS skin, designed-with-detail hair, strong character design language, clean motion, on-brand color palette`。
- **Seedance 2.0 prompt prefix**（表演回退）：强调电影化摄影语言、富有弹性的挤压与拉伸、预备动作、跟随动作、戏剧化光照以及镜头焦段选择。添加：`cinematic Pixar-quality 3D animation, elastic squash-and-stretch performance, Disney-style anticipation and overshoot, dramatic key lighting, lens-specific depth of field`。

当用户选择 `per-shot mixed` 时，应用与该行 `video_model` 字段相匹配的前缀。
