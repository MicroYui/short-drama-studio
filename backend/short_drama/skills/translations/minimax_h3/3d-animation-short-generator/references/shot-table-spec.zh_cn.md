# 标准镜头表规范

## 步骤 5：标准镜头表视频提示词（六列）

角色卡和场景卡确定后，以镜头信息表的形式输出标准化视频提示词。此步骤为必需步骤，不能与分镜或视频生成互换顺序。创建一个名为 `标准镜头信息表` 或 `standard-shot-table` 的画布表格节点或 Markdown 表格。

表格必须严格按照以下顺序包含六列：

| Shot ID & Duration | Continuity Handoff | Reference Anchors (Spatial + Identity) | Hook Type | Shot Description (Per-Second Directives) | Audio & Dialogue Track |
|---|---|---|---|---|---|

各列规则：

- **Shot ID & Duration**：镜头编号和计划时长，例如 `S03 / 6s`。
- **Continuity Handoff**：说明本镜头如何从上一个镜头的结尾画面、道具位置、视线、角色姿态、声音桥接或情绪状态自然延续，以及它如何为下一个镜头的开场做铺垫。这是跨镜头连续性的主干。
- **Reference Anchors (Spatial + Identity)**：四个子字段，全部必填。
  - `Fixed Landmarks`——场景卡中准确命名的地标及其相对于画面的位置（例如 `door-frame: right third`、`kitchen-island: center bottom`）。
  - `Character Positions (camera view)`——镜头中每个角色相对于画面的位置（左/中/右、上/中/下、前景/中景/背景）、面向方向和初始姿势。
  - `Exited Character Status`——对于出现在上一镜头但未出现在本镜头中的任何角色，说明其画外位置和原因（例如 `Mia — exited frame-left, last seen holding apple basket at door-frame`）。
  - `Lighting Baseline`——继承自场景卡的主光/补光/轮廓光方向，以及任何逐镜头调整（例如 `key: warm overhead, fill: cool bounce right, modifier: window-backlit silhouette`）。
  - 另外还要包含身份绑定：获批角色卡的准确名称和获批场景卡的准确名称。
- **Hook Type**：从受控词表中选择一个简短标签，例如 `visual-joke`、`reversal`、`suspense`、`tender`、`chase`、`reveal`、`callback`、`expression-beat`。用于单集钩子分布自检。
- **Shot Description**：景别、摄影机运动、荷兰角设计、表演风格、音效、负面提示词、**视频模型生成备注**（步骤 7 中选择的模型——H3 或 Seedance 2.0——接收略有不同的提示词结构；对于 H3，强调包装关键词以及文字/UI/动态图形清晰度；对于 Seedance 2.0，强调电影化摄影和富有弹性的表演），以及必需的 `Per-Second Directives` 子节。该子节必须将镜头拆解为逐秒指令，例如 `0–1s`、`1–2s`、`2–3s`；对于关键的亚秒级节拍，使用 `2.0–2.5s` 形式的标记。每条逐秒指令必须涵盖以下五个必需元素：
  1. 动作 / 姿势 / 表情（适用时包括挤压与拉伸、预备动作、过冲、跟随动作）
  2. 摄影机运动（推 / 拉 / 摇 / 俯仰 / 手持抖动 / 固定 / 环绕）
  3. 空间位置（角色在哪里、手持什么、画面中出现哪个地标）
  4. 音频提示（旁白 / 对白 / 音效 / 呼吸 / 静默——若有意保持安静，则使用 `silent`）
  5. 向下一秒或下一个镜头的交接（这一秒为下一秒锁定了什么状态）
- **Audio & Dialogue Track**：按照时间顺序记录镜头的完整音频脚本，与逐秒提示分开。字段：
  - `Narration`——带时间范围的画外音文本（没有旁白时省略）。
  - `Dialogue`——台词、说话者、语气、时间范围。
  - `SFX`——带键名、锚定到时间的音效。
  - `Performance Note`——当主角在画外进行旁白时，标记 `narrator-mouth-closed: true`；描述旁白期间的表情变化路径；描述每句对白对应的具体视线和身体动作变化。

全表规则：

- 每个镜头必须通过 `Continuity Handoff` 列自然继承上一镜头的画面状态，并在同一列中为下一镜头做好铺垫。
- 每个镜头行都必须包含覆盖该镜头从首帧到末帧全部时长的逐秒指令，其中包括动作、姿势、表情、摄影机运动、空间位置、声音提示以及连续性交接。
- 逐秒指令必须具体到足以直接生成分镜画格；避免使用“继续移动”这类没有身体、摄影机或道具细节的模糊时序描述。
- 表演必须夸张且富有弹性，符合迪士尼式挤压与拉伸、预备动作、过冲、跟随动作、重叠动作、弧线、快速姿势切换和清晰的喜剧剪影。
- 特写/大特写应与其他必要景别交替使用；避免重复的构图方式。
- 在追逐、失衡、惊讶或肢体喜剧节拍中，必须设计荷兰角倾斜构图。
- 仅在用户明确要求时使用某种对白语言；否则使用最少的、与语言无关的反应，或将对白标为可选/待确认。
- 对于包含旁白或对白的镜头，角色说话的每一秒都必须记录嘴巴是张开还是闭合；默认画外旁白者闭嘴，画内对白者张嘴。
- 已离开画面的角色仍须在 `Exited Character Status` 中至少跟踪一个镜头；只有明确离场并连续两个镜头不在场后，才可不再跟踪。

然后向用户展示选择卡：

- 批准表格并运行自检（推荐）
- 调整镜头连续性
- 让动画更加夸张
- 调整特写/大特写节奏
- 调整荷兰角设计

## 步骤 5.5：镜头表自检关口（必需）

进入铅笔分镜之前，对获批的镜头表执行严格自检。如果有任何检查失败，先修改表格并重新运行自检，再让用户批准分镜制作。

六项必需检查：

1. **钩子密度**：每个镜头都有 `Hook Type`；每三个连续镜头中至少有一个使用 `reveal`/`reversal`/`callback`；开场镜头和收尾镜头都各自包含一个强钩子（`visual-joke` / `reversal` / `reveal` / `suspense` / `tender`）。
2. **单镜头时长**：任何镜头都不得超过 15 秒。如果一个节拍需要更长时间，则将其拆分。
3. **每镜头角色数量**：任何镜头都不得包含超过三个重要角色（指有画内动作或对白的角色）。
4. **空间锚点继承**：对于包含两个或更多镜头的每个室内场景，下一个镜头的 `Fixed Landmarks` 和 `Lighting Baseline` 必须与上一镜头一致，或包含明确的连续性备注（例如 `door-frame moves from right third to center as camera orbits left`）。
5. **逐秒指令覆盖**：从 `0s` 到镜头结束时刻的每一秒都由一条 `Per-Second Directives` 条目覆盖，并且每条都包含全部五个必需元素（动作/姿势/表情、摄影机、空间、音频提示、交接）。允许使用 `2.0–2.5s` 这样的亚秒级节拍，但不能留下任何时间空档。
6. **跨镜头连续性**：逐行阅读 `Continuity Handoff` 列时，应形成一条连续链路——任何镜头都不能从与上一镜头结尾相矛盾的状态开始。任何改变视线、角色位置、道具状态或光照的镜头，都必须明确标记这种变化（例如 `HARD CUT — time skip: 2h`）。

如果六项检查全部通过，在画布表格节点顶部放置 `shot-table self-check: passed` 标记，并向用户展示选择卡：

- 批准自检并绘制镜头分镜（推荐）
- 显示自检详情
- 修改未通过的检查项
- 重新运行自检

如果有任何检查失败，不得进入步骤 6。返回步骤 5，列出失败的行；只有在修复表格并通过自检后，才重新展示分镜批准卡。
