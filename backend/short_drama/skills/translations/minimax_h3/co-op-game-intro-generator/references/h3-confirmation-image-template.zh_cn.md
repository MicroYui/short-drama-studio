# H3 确认图模板

## 核心规则
为双人合作游戏主菜单生成一张精致的 16:9 横向确认图。
图像由两个相互独立的系统组成：
• UI 框架（固定）
• 视觉风格（动态）
UI 框架定义布局、构图、信息层级、交互逻辑、阅读动线、菜单结构和可读性。这些元素必须保持不变。
{visual_style} 只控制艺术表现，包括渲染媒介、材质、色彩语言、灯光氛围、环境风格、角色设计、服装语言、UI 材质、图标语言、字体外观、装饰母题和整体氛围。
改变 {visual_style} 应当像是为同一个专业设计的游戏菜单应用不同的美术指导，而绝不是重新设计界面本身。
如果任何默认描述与 {visual_style} 冲突，应在保留 UI 框架的同时优先遵循 {visual_style}。

---

## 设计目标
创建一张高端商业主机游戏主菜单效果图，采用 16:9 横向格式。画面应同时具备精致游戏宣传图的品质和专业游戏 UI 的清晰度。角色与界面必须自然融合，具有强烈的视觉层级、出色的可读性、简洁的构图和明确的交互焦点。

---

## 整体风格
遵循用户选择的视觉风格：{visual_style}。
所选风格控制渲染媒介、插画风格、材质、配色语言、环境、角色外观、服装设计、UI 外观、图标语言、字体处理、装饰元素和氛围。
所有视觉元素必须属于同一套统一的艺术语言。
不要在同一张图像中混用不兼容的视觉风格。
无论风格如何变化，UI 框架、布局、层级、构图和交互逻辑都必须保持一致。

---

## 色彩方案
从 {visual_style} 推导完整的色彩系统。
使用：
• {main_background_color} 作为主要背景色。
• {ui_body_color} 作为 UI 主体颜色。
• {text_color} 作为主要文字颜色。
• {functional_accent_color} 作为交互高亮色。
• 红色只用于警告、危险或退出操作。
整体配色限制为五种主要颜色。
所有按钮、玩家卡片、图标、边框、高亮、装饰元素、字体和视觉效果都必须遵循同一色彩系统。
避免引入所选配色之外的无关颜色。

---

## 构图
使用固定的 16:9 横向布局。
将 {character_count} 名可玩角色置于中央，作为视觉主体。
UI 环绕角色布置，但不能遮挡角色。
将玩家信息卡放在左上角。
将主菜单纵向放在右侧。
沿底部放置一条装饰性横带，并使其自然适配 {visual_style}（例如缎带、警示条、木板、石板、能量条、卷轴等）。
保持清晰的 Z 字形阅读动线：
Player Cards → Characters → Menu → Continue Button。
Continue 按钮必须始终是主要视觉焦点。
保留充足的负空间和出色的可读性。

---

## 背景
生成从 {visual_style} 自然推导出的背景。
背景应为界面服务，而不是与其争夺注意力。
在所有重要 UI 元素背后保留足够干净的负空间。
只在适合所选风格的位置使用细腻纹理、环境细节和装饰母题。
避免过多视觉噪声、密集装饰、严重污损、刮痕、颜料飞溅或分散注意力的纹理。
整体背景应当精致、高端、现代，并适合商业游戏菜单。

---

## 角色风格
所有角色都严格遵循 {visual_style}。
所选风格决定：
• 渲染媒介
• 身体比例
• 面部风格化方式
• 服装语言
• 材质处理
• 光照响应
• 动画风格
• 角色整体品质
只有角色身份锚点和姿势保持固定。面部渲染、眼睛设计、鼻子简化方式、嘴形、皮肤处理、表情风格和头部比例都必须完全按照 {visual_style} 重新诠释。
任何默认角色风格都不得凌驾于 {visual_style} 之上。

• 边框处理

• 装饰母题
• 色彩渲染
• 灯光处理
• 图标语言
• 字体外观
• 交互效果
它绝不能改变：
• 菜单层级
• 按钮顺序
• 按钮位置
• 玩家卡片位置
• 构图
• 交互逻辑
• 信息架构

• 交互反馈
• 阴影处理

## 按钮布局规则
将所有菜单按钮纵向放置在右侧。
保持一致的纵向节奏。
所有按钮使用同一设计家族。
按钮宽度自动适应文字长度。
所有菜单标题保持单行。
不得自动换行。
不得堆叠文字。
文字保持水平居中。
保持一致的内边距。
按钮之间保持等距。
避免视觉杂乱。

## Continue 按钮
Continue 按钮始终是主要视觉焦点。
使用自然属于 {visual_style} 的强调方式，使其在视觉上占据主导。
可用的强调方式包括：
• 更大尺寸
• 更强对比度
• 更明亮的颜色
• 独特材质
• 鲜明边框
• 灯光
• 辉光
• 雕刻
• 魔法能量
• 全息效果
• 浮雕边框
• 动态视觉提示
如果辉光或霓虹与 {visual_style} 冲突，不要强行使用。
Continue 按钮应当立即吸引玩家的注意力。

生成精致的 AAA 品质商业游戏菜单画面。
角色、环境、UI、字体、图标和装饰元素应当像一个连贯统一的完整作品。
保持高端渲染品质。
强烈的视觉层级。
专业的商业呈现。
高度可读。
均衡的构图。
干净利落的成品效果。

## 负面约束
不要分屏。
不要重复角色。
不要交换身份。
不要丢失身份锚点。除非 {visual_style} 明确要求照片写实，否则不要使用照片写实面孔。不要把真实照片面孔粘贴到风格化身体上。不要让面部风格不匹配。
不要改变发型。
不要出现无法辨认的 UI。
不要出现变形按钮。
不要让界面重叠。
不要出现随机文字。
不要出现随机符号。
不要出现水印。
不要复制游戏标志。
不要使用品牌化界面。
不要混用不一致的图标风格。
不要混用 UI 材质。
不要过度装饰。
不要让背景喧宾夺主。
不要造成视觉杂乱。
不要破坏布局。
不要降低可读性。

## 媒介锁定
渲染为精致的商业游戏主视觉与专业主机游戏主菜单效果图的结合。
界面保持固定。
只有艺术外观根据 {visual_style} 变化。
