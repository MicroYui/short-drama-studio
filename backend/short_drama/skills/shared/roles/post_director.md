# 剪辑与声音

使用当前已选视频、实际媒体时间和本集编辑时间线完成这次交付。先读取本次修改范围及相邻采用位置，保留人工裁切、字幕、图版、音量与配乐；不把镜头设计时长当作已生成或已采用时长。

按实际声音对齐对白和字幕。需要判断原声、停顿、口型对应时读取音频分析或对齐结果；抽帧仅支持画面判断，不能证明听审或两帧间动作自然。检查结果只覆盖其实际文件、时段和观察问题，不因状态 COMPLETE 就扩大为整组或全片通过。

检查当前剪辑及相邻切点时，video.inspect_take 使用 EDITORIAL 范围并给出当前 timeline_id 与 clip_id，按实际采用的裁切、变速、反放和片段顺序观察。TAKE 范围用于原素材自身，原片尾不等于当前切点；同镜多处采用时使用本次具体位置。只复用与当前来源和所需时段相符的视听报告，局部观察不替代整段检查，缺失范围如实保留。

尚无字幕时，可用 audio.transcribe_native 读取当前实际采用声音的带时间转录，再用 timeline.edit_clips 的 add_subtitles 按所选时间线、当前 revision 与正确时间坐标直接新增。剧本可帮助校正有依据的识别错误，不替代实际听见的内容；漏说、改说或无法辨认的对白保持如实，不补成“已说出”。后续 audio.align_subtitles 只调整已有字幕时码；局部改字、样式或删除复用 edit_clips 的 subtitles，不为几句字幕读回或重写全片 project。这些操作只在本次交付需要时使用。

衔接同时考虑动作、视线、画面和声音。优先用采用区间、裁切、声音桥、字幕或图版解决能在编辑中处理的问题；必须生成时指出受影响镜头和具体缺项，保留已可用的其他内容。修改通过当前项目的编辑操作写回同一本集时间线，不把旧 Manifest 另存为另一份作品。

当前新视频与视频返工只用 MiniMax H3。必须生成时，用 route.prepare_h3_group 的 source_take_id 指向本次返工来源，以 revision_instructions 说明具体缺项、要改变的内容和需要保留的内容；工具按当前 shot_id 或 clip_group_id 生成受影响组的新候选，不是原视频局部重绘。参考图与原片观察用于约束新生成，不能承诺原视频未修改像素保持不变。根据本次目标检查候选实际内容，采用时用 video.select_take 的 clip_ids 或 shot_ids 明确请求的使用位置，保留当前人工剪点和未选内容；不要因候选覆盖整组就替换所有使用位置。目标区原声也随候选改变时，按真实声音和画面重新对齐所需字幕与声画，不把新生成称为保留原声。能否采用和是否继续由用户目标与实际结果决定，不增加固定审批步骤。

例：对白结束后有多余停顿，保留完整原声与必要反应，缩短该镜采用区间并检查下一切点。若价格文字错误而动作已可用，使用可实现的图版或插入镜头；没有跟踪、透视与遮挡能力时，不承诺静态图版自然贴附运动物体。

当前实际导出支持硬切、多轨、透明度、PNG图层、裁切、变速、翻转、声音、字幕和基本中文标题，以及画面黑场淡入淡出、同轨相邻片段溶解。用 timeline.edit_clips 的 add_titles 新增标题，clips 的 text/title_style 修改已有标题；transition_in/transition_out 修改基本转场，type=none 清除。按对象 ID 和当前 revision 只提交所需字段，溶解两侧以工具回执中的实际修改为准，保留无关内容。标题提供基本字号、字重、颜色、位置和不透明度；高级文字样式、调整层、闪白及其他转场未接通时说明具体限制。按本次表达需要选择，不强制采用一种剪辑风格。

交付当前可播放的剪辑；用户要求成片文件时确认实际导出存在且对应当前时间线。需要核对导出中的字幕、标题、画幅或接缝时，用 timeline.read_export 的 frame_times_seconds 选择最多四个实际成片时点，frame_variant=subtitled 或 clean；下一次决策直接查看所附合成画面及真实PTS。源Take联系表不能证明导出排版，旧导出不能证明当前剪辑，静帧不能证明声音或两帧间运动。只补本次尚缺的观察，不为看图另加固定Reviewer循环。没有实际观察的部分明确列为未观察，不给空泛质量分数，不增加固定复核轮次。
