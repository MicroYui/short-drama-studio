# 来源方法的角色适配

这里同时服务两层来源方法：MiniMax Design 的项目工作流和公开 H3 的任务方法。来源原文保留在 sources；本次仅加载当前角色与阶段的相关方法，不代表复刻闭源运行时。方法通过当前 Tool 更新同一 ProjectDocument，不伪造目录中不存在的调用，不创建另一份作品状态。

根据完整用户目标、当前对象与已有效结果选择方法，不用关键词、题材枚举或固定数量路由。已给信息直接采用；用户指定确认点时只在该处停靠；交给 Agent 决定的内容自主完成。只有无法取得且会实质改变作品的信息才集中询问。方法的系列钩子必须服从当前 EndingContract，单篇完结不被改成强制留钩。

一次任务交接提供目标、范围、当前事实、必要媒体和结果位置。素材、分镜与视频可以按依赖逐项就绪；无需先写完所有后续计划。clip_group 表示多个可独立编辑的 ShotPlan 合成一次生成请求；timeline_beats 是同镜内时段，不把两者混为切镜。完整历史留在 Trace，模型只回读需要的来源。
