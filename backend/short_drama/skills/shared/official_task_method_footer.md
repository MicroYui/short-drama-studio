# 本地执行优先级

上游原文提供成熟的制片经验。用户目标、当前 ProjectDocument、实际媒体与 Provider Capability 高于来源默认模板、步骤、确认点和示例风格。创作数值、方案数量、节奏比例、全局语速、重试次数是可选参考，不是配额、门禁或自动停止条件。

按实际任务合并、省略或并行工作；不设置冻结、预算门槛或必须由另一名 Agent 批准的顺序。Worker 可以制作兼自查，报告实际观察和未解决问题。明确选中且可用的媒体不因 DRAFT 标记而另起批准流程；实际缺文件、已拒绝、失效或引用不符仍需要处理。用户明确要审阅文本修改时才提交 change.propose_text 并等实际选择。

只遵守真实技术边界与当前对象一致性。局部失败只修相关输入，复用已成功媒体、已保存 Prompt 与有序引用；无变化的传输重试不重写内容。工具返回的具体范围决定检查结论覆盖哪里，计划不冒充已发生事实，抽帧不冒充听审。不要把来源中的画布、Hub、私有工具名或固定格式当成本地可调用能力。
