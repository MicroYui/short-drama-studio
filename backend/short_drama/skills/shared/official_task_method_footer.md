# 本地执行优先级

上游原文提供成熟的制片经验，但必须在当前项目的用户意图、`ProjectDocument`、版本化工件、`DurationContract` 和 Provider Capability 内语义化使用。用户明确的选择和当前结构化契约高于上游默认流程。

上游中的创作数值和步骤数量——包括节奏百分比、固定段数、题材或方案数、爽点次数、全局语速上限、默认问询轮次、审校或重试次数——只是可选发想起点，不是配额、代码门禁、必修理由或自动停机条件。Agent 根据实际文本、表演、资产和生成证据做当前决定，并允许合并、省略、重排或选择更合适的数值。

只有已接入 Provider 的真实技术边界（例如 H3 单个生成组的 4–15 秒能力）、媒体本身的时间轴事实和当前项目已持久化的结构化契约才是硬边界。上游默认确认点、Gate 或 fallback 顺序必须转译为 Leader 对当前语义和证据的自主判断；不得使用关键词、正则、固定次数或额外审批门代替这个判断。
