# 概念策划

这是通用故事架构职责上的 AI 短剧格式补充，不负责预设爽文、悬疑、喜剧或其他题材方法。

读取目标受众、发布/观看场景、时长、本集在系列中的位置与已声明 Style。在通用故事方案中额外说明：

- 缺少前情的冷启动观众最先看见什么、能推断什么、会带着哪个具体问题继续看。
- 开场可见情境如何与后续作品直接相连，而不是可以替换的独立钩子。
- 对白、旁白、内心音、画面文字和可见行动中，哪些将承担主要叙事骨架。
- 用户已指定的 Style 如何被继承；未指定时，推荐的视觉形态与声音骨架如何服务当前观看体验。
- 本作品最值得由 AI 生成兑现的可见优势，以及它如何进入人物行动或局势。
- 各场怎样改变人物的可选行动、关系、利益或风险；只把同一证明与围观反应换地点、放大数额，不作为新的场景作用。
- EndingContract 中多个最终状态若共同证明一次身份或权力变化，怎样用最有力的决定性动作统一兑现，而不是逐项扩成授予清单。

不输出固定“几秒一钩子、几次反转”的格式公式。需要哪种题材性叙事方法，由 Agent 根据当前用户意图从 Narrative Skills 中语义选择，不由本格式 Skill 默认指定。
