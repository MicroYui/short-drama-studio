# AI 原生短剧的创作形态与节奏维度

本文件提供 Agent 思考创作方向时可选的维度，不是视觉类型枚举、固定镜头模板或验收清单。AI 仿真人、二维/三维、动态漫、真人与 AI 混合只是常见例子，Agent 可以根据用户目标形成其他风格或组合。

## 项目自己的 Style 才是依据

先读取用户要求、来源内容、参考素材和当前 Bible，再在 `style.medium`、`cinematography`、`color`、`texture` 与 `forbidden` 中用自然语言记录本项目真正需要长期保持的选择。

- 用户已经给出风格时，保留其表达，不用格式 Skill 替换。
- 用户没有指定时，Agent 可以从故事目标、受众体验、素材条件和当前 Tool 能力出发提出有理由的创意选择。
- Style 是可修改的项目工件，不是代码枚举。不要因为选择了 AI 短剧，就自动补上“真人写实”“动漫感”或任何固定审美词。
- 后续资产、镜头、生成、声音和审核都以当前 Style 为准；临时参考图或 Provider 偏好不能反向改写它。

## 可组合的创作维度

### 视觉呈现

Agent 可以考虑角色与世界以写实生成、风格化绘制、三维、平面图形、实拍素材、混合媒介或其他方式出现。关键不是归类，而是这种表达如何服务故事、情绪和项目辨识度。

### 运动语言

连续表演、关键姿势、局部运动、有限动画、图层运动、摄影机运动、稳定画面和蒙太奇都可以成立。运动量由当前节拍要表达的变化决定；“动得多”与“更高级”没有必然关系。

### 叙事载体

对白、旁白、内心音、动作、构图、环境变化、声音、字幕和画面文字可以按项目需要分工。不要默认所有人物都持续说话，也不要让声音逐字重复画面已经清楚表达的内容。

### 节奏组织

分别观察故事状态、画面状态和声音状态何时发生变化。它们可以同时落点，也可以错开形成期待、反差、停顿或回收。快慢、疏密和静动都应服务当前段落，而不是服从固定秒数、镜头数或反转数。

### 连续性重点

不同项目需要保持的内容不同，可能包括角色身份、造型语言、空间关系、道具状态、动作边界、声音身份或媒介切换规则。Agent 只突出与当前 Style 和镜头职责有关的维度，不把某种风格的观察项推广为所有作品的硬要求。

### AI 表达优势

Agent 可以寻找生成式制作能放大本故事独特性的部分，例如难以常规呈现的世界、角色、转化、尺度、主观体验或视觉规则，但奇观本身仍需改变观众理解、人物选择或情绪结果。不要为了容易生成而把作品收缩成通用模板。

## 各角色如何使用这些维度

- 概念策划说明推荐的整体 Style 与它服务的观看体验，不必先把作品塞进固定子类型。
- 编剧决定哪些内容由人物行动、声音或画面承担，并把复杂事件写成可理解的变化，而不是迎合某个模型的固定句式。
- Planner 与 Director 把剧本转成清楚的镜头职责，按需要分配运动、构图、声音和剪辑，不预设真人拍摄语法或动画语法。
- 资产角色维护当前项目声明的身份与风格锚点，只生成实际镜头需要的版本。
- Route Agent 和 Prompt Compiler 服从 ShotPlan、Style 与 Provider Capability，不擅自追加写实、卡通、电影感、皮肤、镜头速度或动作幅度。
- Reviewer 判断成片是否实现项目自己声明的表达；只有当某个偏差违背当前 Style、剧情事实或镜头职责时，才把它列为问题。

## 明确不写死的内容

- 不要求某种人物质感、脸型、统一材质或固定画风。
- 不规定必须使用正反打、特写、快速切镜、完整人体运动或有限动画。
- 不规定对白与旁白的比例、语速、音乐强度或字幕样式。
- 不把某个 Provider 当前擅长的效果写成 AI 短剧的长期定义。
- 不新增视觉形态状态机或质量门禁；Agent 可以解释并覆盖这些建议。
