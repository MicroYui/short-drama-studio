# 数字人口播

## 成片目标

创作以口语表达为主的数字人视频，通过稳定的主播身份、自然清楚的语音、可信的口型同步与表演，以及易读且有用的辅助画面，准确传达用户希望观众理解、相信、记住或执行的信息。

数字人口播描述的是信息组织和表演重点，不绑定某个数字人 Provider、音色模型或固定模板。原生音视频、独立配音后驱动、真人参考和其他实现路线都由 Agent 根据当前 Tool 能力选择。

## 内容与语言原则

- 来源事实、品牌主张、专有名词、数字、引用和行动指令必须保持准确；不要为了口语感改变原意。
- 先按听觉理解组织内容，再考虑字幕和画面。句子应可发音、可换气、指代清楚，重点与段落边界能被听出来。
- 开场尽快说明话题和观看收益，但不要求用冲突、夸张承诺或固定话术获取注意。
- 重复可以用于强调或帮助理解，但应由语义和受众需要决定，不机械复述。
- 专业内容可以保留必要术语，同时用上下文、例子、图形或补充画面降低理解负担。

## 主播、声音与表演原则

- 主播的人脸、发型、服装、声音身份、语言、口音和整体表达气质属于跨段连续性。
- 语音内容、发音、停连、重音、语速和情绪是表演基线。口型和身体动作应跟随同一版语音，而不是分别猜测。
- 目光、表情、头部动作、姿态和手势应服务语义、态度或段落变化。持续点头、随机挥手和无目的大动作会削弱可信度。
- 不把“始终直视镜头”当成硬规则。看镜头、看屏幕、看演示物或短暂移开视线都可以成立，但要符合场景和表达关系。

## 辅助画面与字幕原则

- B-roll、图表、屏幕演示、标题和关键词只在它们能解释、证明、示范或强调时出现。
- 辅助画面不能与口播表达相矛盾，也不能为了增加变化频繁打断主播的情绪和可信度。
- 字幕忠实于本次采用的文本，按语义和呼吸断句，并避开嘴部、眼神、手势、产品或演示区域。
- 信息密集段落应通过内容重组、停顿、示例和画面分工解决，不只依赖缩小字幕或加快语速。

## Agent 行为边界

- 本 Skill 只描述稳定的数字人口播差异；跨阶段方法可参考 `workflows/end_to_end.md`，实际工作顺序和完成边界由本次目标及当前依赖决定。
- 先读取本次范围明确采用的文案、形象、声线及 Take，以及所需的关联事实；当前可用媒体不以补审批标记为前提，实际拒绝或失效内容按具体问题处理。局部改词只影响真实依赖该音频或口型的下游。
- Provider 的时长、分辨率、音频格式、参考数量与口型能力以当前 Tool Schema 与 Capability 为准，不写死在类型 Skill。
- 用户可以覆盖本 Skill。Agent 应说明覆盖会如何影响准确性、听感、身份连续性、口型或画面可读性，不增加固定门槛。
