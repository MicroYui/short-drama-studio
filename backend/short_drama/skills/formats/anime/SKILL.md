# 动画叙事

## 成片目标

创作与既定视觉语言一致的动画叙事作品，使故事、角色设计、表演、构图、色彩、线条、材质、合成和运动方式共同服务于同一体验。

“动画”是媒介与表现语言，不绑定二维、三维、定格、漫画动态化、写实或某个模型。项目可以有意采用有限动画、夸张变形、非真实透视、跳帧或图形化运动；Agent 要保护这些选择，而不是默认用真人摄影或物理写实纠正它们。

本 Skill 适用于动画视觉语言本身是主要产品目标的作品。AI 原生短剧即使采用动画、插画或动态漫画面，也不自动切换到本 Skill；这类项目可继续由 `AI_SHORT_DRAMA` 负责连续叙事与生成式生产，并在 Bible Style 中自由描述其画面语言。

## 视觉语言原则

- 尽早明确世界规则、角色造型基准、轮廓、比例、服装、色彩、线条、材质、背景处理、光影与运动节奏。
- 角色身份锚点、场景/道具设定和单镜构图关键帧承担不同职责；临时生成的镜头画面不能反向成为新的角色母版。
- 构图、姿势、表情、关键动作和节奏间隔是动画表演的主要控制点。运动量越大不代表表达越强。
- 动作可以通过预备、主动作、反应、停顿和余韵组织，也可以有意省略中间过程；关键是观众能理解动作与情绪关系。
- 镜头覆盖按照画面设计和叙事需要确定，不照搬真人拍摄的正反打、景别数量或连续运动规则。

## 连续性与风格化原则

- 跨镜保持角色轮廓、脸型、发型、服装、比例、色板、道具状态、空间关系和世界规则；有意变形、换装、色彩转场或风格跳变应作为明确剧情/表现决定记录。
- 区分“有意的有限动画、重复循环或静止保持”与“模型卡顿、身份漂移、肢体融化、背景闪烁、错误补间”等缺陷。
- 只为当前镜头准备需要的视角、表情、姿势和状态，不把完整设定集当作每个项目的固定前置清单。

## 声音与字幕原则

- 声音、对白、音乐和音效要与动画节奏、动作落点和情绪变化共同设计。
- 对白场景既要检查角色声线与口型，也要保留动画允许的风格化同步；字幕和图形不遮挡关键表情、动作轮廓或画面设计。

## Agent 行为边界

- 本 Skill 只描述稳定的动画类型差异；跨阶段方法可参考 `workflows/end_to_end.md`，实际工作顺序和完成边界由本次目标及当前依赖决定。
- Provider 参数、模型版本、引导方式、参考数量、分辨率和时长从当前 Tool Schema 与 Capability 获取，不写死在类型规则。
- 用户可以覆盖本 Skill。Agent 应解释覆盖会如何影响视觉语言、角色连续性、可生成性或剪辑，不增加固定风格门槛。
