# 通用视频

## 类型定位

通用视频是没有更具体格式约束时使用的创作 Skill。它不等于“套用一套平均化模板”，而是要求 Agent 从用户声明的观看体验、内容来源、媒介选择和交付场景出发，建立当前项目自己的评价标准。

剧情密度、冲突、对白、新奇性、反转、视觉风格、画幅、语言和镜头速度都不是默认必选项。作品可以是叙事、说明、观察、氛围、表演、实验影像、品牌表达或这些形式的组合。

## 稳定创作原则

- 先说明作品要让观众理解、感受、相信、记住或完成什么，再决定结构和镜头。
- 有来源剧本、事实、品牌信息或用户素材时，忠实度优先于 Agent 自行增加的戏剧性。
- 每个场景和镜头都应承担可说明的作用，但作用可以是信息、情绪、观察、空间建立、节奏、表演或转场，不局限于剧情推进。
- 留白、静默、重复、固定镜位和长镜头只要能产生预期体验就可以成立；快速切镜和高密度对白也只有在服务目标时才采用。
- 形式选择应保持一致：真人、动画、屏幕录制、档案素材、图形、数字人和混合媒介可以组合，但组合关系要有清楚理由。
- 审看依据是项目自己声明的意图和实际成片，不把某种平台套路、电影语言或 Provider 偏好当成普遍标准。

## 连续性与修改原则

- 对需要连续观看的内容，维护人物、场景、道具、时间、空间、声音、图形和风格状态；对有意跳切或非连续表达，明确它是创作决定而不是漏检。
- 用户只修改局部时，先读取相关当前内容和实际依赖，只重做真正受影响的剧本、资产、镜头、Take 与时间线边界；需要相邻或上游事实时按范围回读。
- 当前明确选用、文件可用且仍符合本次意图的工件优先复用，不为了让流程完整而重新生成或补审批标记；实际拒绝、失效或不匹配的内容按具体问题处理。

## Agent 行为边界

- 本 Skill 只描述稳定的通用创作判断；跨阶段方法可参考 `workflows/end_to_end.md`，实际工作顺序和完成边界由本次目标及当前依赖决定。
- Provider 的模型版本、媒体数量、分辨率、时长和输入组合以当前 Tool Schema 与 Capability 为准，不写入类型规则。
- 所有建议均可被用户覆盖。Agent 应解释选择会如何影响表达、连续性或交付，但不把建议升级成固定配额或通过门槛。
