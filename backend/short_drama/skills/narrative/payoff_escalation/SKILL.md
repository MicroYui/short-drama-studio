# 回报递进

把观众期待的胜利、反击、认可、地位、资源或主动权写成人物能看见、对手必须回应、后续局势真正改变的结果，不只是主角自我宣告。

主要回报还需要一条观众能复述的决定性因果：主角做了什么，哪个关键条件因此改变，结果为什么随之发生。权威表态、到账提示、排行榜或数据大屏可以确认胜利，但不能成为唯一让胜利成立的原因。若结果依赖价格、资源、规则或交换条件，只呈现足以理解胜负的决定性信息，不扩写成完整审计或制度流程。

先看人物与局势是否真正进入了新的状态，而不是把同一种证明、围观反应或授予仪式换个地点再演一遍。核心胜利已经不可逆地落地后，后续内容应带来新的选择、代价、关系后果或简短余味；如果只是再次确认同一身份和同一服从关系，就把它并入高潮或压成一个利落的收束动作。

基本回报链是“压力或质疑 → 主角的具体行动 → 他人可见反应 → 新的结果或选择空间”。它用于观察整集和真正改变状态的主要段落，不是要求每场都逐项执行、更不是按固定次数重复的模板。

递进可以来自反应范围扩大、私下认可变为公开承认、风险或对手升级、主角获得新身份/资源/选择，也可以是人物从被动应对转为自主定义规则。选择与题材和人物相符的维度，不默认每个作品都要羞辱对手、公开打脸或不断升级权威。

用多种回报方式避免单调：他人失语、立场转变、群体情绪、资源到手、选择权扩大、主角松弛的回应，都可成为可见落点。结尾要保护本篇已赚到的核心回报，不用一个突然的新危机将其全部撤销。

权威已经正式授予、资源已经实际到手或关系已经完成转变后，下一场优先展示主角如何使用这个新状态、拒绝什么、选择什么或承担什么，不再用文件、挂牌、让位或另一轮围观重复证明。目标时长是表演空间，优先保留最有区分度的兑现，让动作、反应和最后一句真正有时间落下。
