# 参考意图、保留范围与声音

## 参考素材各自负责什么

先根据当前明确的媒体和本镜目标说明每项输入贡献：身份、场景、材质、画风、构图、动作、镜头、音色或声音片段。素材可以承担多个已经确认的用途，但不能因为文件存在就默认全部继承。未上传的图片、视频或音频不产生可执行参考标签。

对于每项参考，同时说明保留什么和不取用什么。人物卡中的多个视角描述同一个主体，参考图背景、标注和文字未必属于最终画面。产品图不能证明看不见的结构或使用效果。普通参考、硬首帧和硬尾帧分别按当前路线的实际约束处理。

直接复用能满足当前镜头的媒体。确有身份、关系或布局缺口时只补所需内容；用户已经选择直接制作时，不因方法示例再要求一轮参考策略确认。必要信息仍缺失且会实质改变结果时，说明具体缺项并保留已完成内容。

## 将运动写成可观察过程

Prompt 描述起始状态、动作发起者、运动路径、接触或作用关系、其他主体反馈及结束状态。连续镜头内的时间段不自动意味着切镜，明确单一主运镜与主体运动怎样配合。

镜头、时间、画幅、参考顺序和逐字台词来自本次保存的分镜及生成单元。最终字段、英文描述规则、模式首行和标签使用当前 required_prompt_schema 与适配器提供的 prompt_label；本方法不定义另一套输出骨架，也不改写已经绑定的路线。

实际时长、清晰度、帧率、引用数量、音频和编辑能力来自当前 Provider Capability。旧案例中的默认值不写回请求，也不因内容类型更改当前模型。请求过长时压缩重复修辞并保留锁定事实，不能设最低字数或暗中删掉对白。

## 文字、界面与源视频保留

准确文字逐字列出，并说明在哪里、何时、以何种层级出现。字体与布局重要时采用真实设计图、图版或后期文字层；不能把无字画面统一当作修复方式而删掉用户的标题。

已有源视频的修改先声明允许变化的部分与需保持的主体、场景、时间关系、声音和构图。裁切、字幕、速度或拼接优先使用当前编辑工具；只有当前 Provider 与工具支持对应生成操作时才走视频生成，不凭教程声称存在编辑接口。重制结果不是原视频像素级保留。

## 声音的职责与连续性

区分画内对白、画外旁白、环境、动作声与非叙事音乐。为每段发声指明说话人、准确内容、局部时间和声音身份；同一句跨画面继续时只发声一次。引用音频时明确是音色、节奏、完整复用还是局部复用，按实际参考标签表达。

用户要求静音、无配乐或只保留某声音时原样保留，不用默认声场补回。对白时长应能自然说完；语言、口音与语气以实际角色和本镜为准。静帧可用于检查口部姿态，音频和口型同步需要实际声画观察。
