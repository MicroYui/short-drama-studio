# 本地使用与恢复

本文说明当前产品入口与恢复方式。各项实际验收状态见[成熟化交付清单](product-commercial-delivery.md)；内部候选包与正式签名发布分别记录，不用本文代替验收结果。

## 开始一个项目

1. 打开 Short Drama Studio，新建项目。一个项目可包含多集，共享人物、场景、道具和声音；各集有自己的剧本、镜头和成片。
2. 在“设置与创作方法”配置语言、图片和视频服务。语言角色统一使用有效配置中的 `gpt-6-astra / xhigh`；图片、视频与声音服务独立配置。当前视频生成只使用 MiniMax H3。
3. 向制作助手说明本次想交付什么。只需要剧本时明确提出剧本要求；需要视频时说明内容、时长、画幅、对白和结束动作。Agent 根据目标完成工作，实际执行与生成状态显示在右侧。
4. 在“项目资产”查看已生成或导入的具体媒体；在“镜头”中查看完整设计、引用和视频。进入“编辑分镜”后更换引用并保存，正文引用与生成输入保持关联。

普通启动的数据目录为 `~/Library/Application Support/ShortDramaStudio/`。独立测试目录由 `STUDIO_APP_DATA_DIR` 指定。不要在两个运行实例中同时使用同一个数据目录。

## 修改、剪辑与导出

- 场次、分镜与剪辑草稿会留在本机；正式保存后才成为项目当前内容。切换页面或重新打开后可恢复草稿。若后台内容也发生变化，先查看提示再决定如何保留本次修改。
- “剪辑镜头”只打开本次使用的片段、声音与字幕，局部时间从零开始。保存会同步本集成片。一个镜头被使用多次时，先选择要修改的位置。
- “剪辑成片”打开本集完整时间线。可编辑裁切、位置、声音、字幕、标题、基本转场与基础调色，使用撤销恢复误操作。设计时长、素材时长和当前采用时长分别显示。
- 保存后选择“导出”，核对画幅、帧率和字幕。导出过程中可查看进度；完成后下载当前文件。后续修改不会改写旧的导出文件，分享新结果前重新导出。

需要新画面时，向 Agent 说明要重做的镜头、具体问题及需要保留的其他内容。当前使用 H3 生成候选，再按实际质量决定是否用于指定位置；这属于镜头/生成组重生成，无法承诺只改变原视频的嘴型或单个局部。原素材保留，未选镜头与人工剪辑应继续使用已有结果。暂停供应商任务表示停止本地推进，已提交的远端任务可能仍继续处理。

检查成片字幕、标题、画幅或接缝时，可让 Agent 看指定导出的具体时点。实际导出画面读取随 r4 候选提供；旧导出和当前剪辑的修订会分别标明，静止图片检查不能代替对白听审或整段播放。只读取技术信息时仍不需要抽帧。

2026-09-16 按用户要求收回 Kling 操作和设置入口。已有试验失败记录仍可查看，不需要为当前产品补充 Kling 凭据。

## 保存项目、媒体与迁移

日常结构化内容和制作状态保存在 SQLite；图片、视频与音频保持为文件，数据库保存关系与路径。JSON、Markdown 和项目包用于交换、查看和迁移，不作为另一份日常可编辑真相。只复制数据库不会自动带走媒体文件。

使用“项目收集与迁移”收集项目包，可看到阶段、文件数量与字节进度。后台任务开始后可以关闭面板继续编辑，再打开查看同一个任务。完成的包可下载；原生端可打开包所在文件夹。取消会清理未完成的包，保留当前项目。

项目包备份已保存的项目内容、媒体和制作记录，不包含应用配置、服务凭据或未保存草稿。收集前保存需要保留的编辑，完成后把包另存到备份位置，并核对一次导入结果。

导入项目包时先等待文件上传及后台任务确认，再查看导入进度。成功后打开导入项目并检查媒体。旧制作记录随包保留，历史 Agent 或供应商任务不会作为新制作重新执行。单独“导出制作记录”用于查看本次目标、动作、实际模型、输入输出、用量和文件索引。

## 遇到中断时

| 情况 | 处理方式 |
| --- | --- |
| 保存失败或连接暂断 | 保留当前草稿，连接恢复后再保存；不要反复刷新来丢弃输入。 |
| 想暂停制作 | 点击“暂停”；已开始的操作先结束并落盘，随后可在同一任务继续。 |
| 图片或视频返回不确定状态 | 查看具体制作任务和已有远端记录，先恢复或对账；不要因为界面没有立即显示结果就重复生成。 |
| 媒体文件移动或缺失 | 在项目媒体的提示中重新定位文件，确认绑定恢复后播放或导出。 |
| 本地声音资源不可用 | 在设置中查看具体资源状态，准备或重试；资源不可用不应阻止编辑已有内容。 |
| 麦克风录音无法开始 | 查看应用与 macOS 的麦克风授权及实际错误。也可以导入已有声音；不需要录音即可进行普通剪辑。 |
| 应用本地服务启动失败 | 启动页显示失败阶段和原因；打开日志文件夹查看本次日志，处理原因后重试。重试不会清空已保存项目。 |

ComfyUI 属于可选外部服务，应用包不包含其节点、依赖或模型。主制片和剪辑不依赖它，配置与已验证范围见[ComfyUI 使用说明](comfyui-local-integration.md)。

商业分发前需要的签名、公证、组件许可和供应商条件见[分发条件复核](research/2026-09-16-commercial-distribution-review.md)。
