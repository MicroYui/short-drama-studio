# Phase 12：跨剧本资产 Agent 与同源场景视图

## 目标

Phase 12 不再重复《别相信我》，而是用全新真人都市职场轻反转短剧《明天别来了》验证跨剧本泛化。用户只提供锁定剧本，`AUTO_DRAFT` 自动完成规划、资产补全、逐镜参考选择、关键帧、H3 768P 候选、质量复核、局部修复、时间线、字幕和单版成片导出。

本阶段的核心不是“多生几张图”，而是把照片与参考资产沉淀为 Agent 可调用的通用 Tool，并由 Agent 管理其生命周期。

## 照片如何生成

当前链路分为决策层和执行层：

1. Production Planner 把每个镜头需要的人物、场景、道具、角度、景别和状态写成结构化 `reference_needs`。
2. Asset Agent 先搜索当前项目和跨项目已批准资产，只有无法覆盖时才生成新图。
3. 角色生成单人全身身份母版，场景先生成一张无人 `Master Wide`，道具生成一张中性产品母版；不再把三视图拼贴板或多格参考板当成默认母版。
4. 镜头需要反打、交互区、侧面、特写或道具状态时，GPT Image 2 以当前批准母版为编辑输入派生单一视图，不从空白提示重画。
5. GPT-5.6-sol 把候选与母版做身份、服装、空间拓扑、物件结构和用途对照；通过后登记到 `ReferencePack`，并保留 `lineage_root_version_id`。
6. `ReferencePlan` 逐镜选择少量最合适的同源参考供关键帧和 H3 路线使用。

三视图仍然可以生成，但它是 Agent 根据多角度、全身动作或特定构图需求选择的补充视图，不是每个角色的固定前置任务。

## Asset Agent Tools

| Tool | 责任 | 是否硬阻断 |
| --- | --- | --- |
| `search-assets` | 在当前项目与跨项目目录中按资产种类、主体、角色、角度、景别、标签和文本相似度搜索 | 否 |
| `inspect-coverage` | 根据全部分镜需求计算已满足与缺失的参考视图 | 否 |
| `import-asset` | 把可复用的已批准图像复制为目标项目的可审查草稿版本 | 否 |
| `ensure-asset-view` | 从当前批准母版派生本镜头所需的单一视图 | 否，有界重试后可回退母版 |
| `review-and-register-asset` | 语义检查候选，通过后登记源谱、角色、角度、景别和标签 | 否 |
| `select-shot-references` | 为每个镜头选择最小必要参考集，同源系谱优先 | 否 |

Agent 负责“为什么需要、用哪张、是复用还是派生”；Tool 负责本地文件、Provider 调用、任务恢复、版本、源谱和结构化结果。如果用户在 `GUIDED` 中修改或忽略 Agent 建议，底层工具不强制其采用某个视图。

## 跨项目目录与同源系谱

Phase 12 的“资产库”不另建一个与项目脱节的系统：已批准 `AssetVersion` 和 `ReferencePackEntry` 本身就是目录真相源。搜索可返回当前项目或其他项目候选，导入仍需经过目标项目的语义审查，避免名字相似但人物或场景实际不同。

每个派生视图记录当前批准母版为系谱根。母版替换后，旧系谱不再被当前镜头自动选中；旧产物仍保留，但不混入新的身份或空间版本。

## 验证剧本：《明天别来了》

**类型**：真人都市职场轻反转，普通话，9:16，目标 55–60 秒。

**角色**：

- 许知夏，25 岁，实习设计师，肩长黑发，深绿色针织上衣、炭灰长裤、白色运动鞋，克制但倔强。
- 陈屿，36 岁，项目总监，短发，藏蓝衬衫、灰色长裤，平静直接。

**场景**：深夜创意公司办公区；电梯厅、直走廊和走廊尽头的玻璃会议室是同一连续空间。走廊冷白光，会议室暖光，避免可读 Logo 和招牌文字。

**道具**：员工工牌。开始为白卡蓝挂绳，被取下后由陈屿持有；揭示时会议桌上有深色挂绳的新工牌，不展示可读字。

**锁定台词**：

1. 陈屿：“工牌给我，明天别来这个工位了。”
2. 许知夏：“方案是我做的，至少让我讲完。”
3. 陈屿：“谁说不让你讲？”
4. 陈屿：“客户点名，让你来带这个项目。”
5. 许知夏：“所以，我不是被辞退？”
6. 陈屿：“是实习期结束了。”

**目标分镜**：

| Shot | 时长 | 内容 |
| --- | ---: | --- |
| S01 | 5s | 电梯厅 Hook，陈屿索要工牌，台词 1 |
| S02 | 15s | 走廊简单路径的跟拍长镜头，许知夏追上并说台词 2 |
| S03 | 7s | 陈屿停步反打，台词 3 |
| S04 | 6s | 会议室暖光揭示，桌上新工牌与安静的项目成员，无台词 |
| S05 | 10s | 陈屿说台词 4 |
| S06 | 8s | 许知夏反应并说台词 5 |
| S07 | 7s | 陈屿结尾台词 6，留在新工牌与人物表情上 |

目标总时长 58 秒。这是导演意图，Planner 可在不更改锁定台词、不破坏反转和 55–60 秒目标的前提下做景别或剪辑微调。

## 时长适配

H3 可返回比导演计划更长的素材。时间线不再默认吞入整段 Take，而是以 `ShotPlan.duration_seconds` 为编辑目标选择窗口：

- 对话镜头默认从素材开头保留，避免从半句台词进入。
- 无对话且存在动作/道具状态变化的镜头优先保留素材尾部，确保 `action_out` 和 `prop_state_out` 进入正式时间线。
- 若 Take 比计划短，不用冻结帧强行补齐，按可用时长编排。

这一通用编辑规则把首版 63.29 秒全长素材时间线收整为 58.00 秒，同时保留了 S01 交接动作的完成态。

## 范围边界

- 不新增工牌、走廊、电梯厅或会议室专用领域字段。
- 不把 Agent 的视图推荐变成用户硬审批门。
- 不新增声音 QA；已有检查继续运行，参考声线仍为可选输入。
- 不为了形式上的“RAG”再引入向量数据库；当前规模用 SQLite 结构化过滤、标签与轻量语义排序即可，目录规模或召回证据需要时再升级。
