# 日常制作与局部修改

当前原生版本为r30，沿用已有项目profile。首片《最后一把伞》在r21完成，《早餐带上》第3镜局部补拍在r26完成，第二片《修好了》在r27按用户要求结束观察并暂停，尚无完整导出。r30重开后项目、剪辑和任务全文相同，保持暂停。用户认可当前稳定性测试，本轮停止追加效率实验；已验证的局部内容与声音保留、暂停重开和导出能力，不代表全部质量或原效率目标通过。实际范围见[本轮记录](research/2026-09-17-daily-production-goal.md)与[恢复核对](../output/daily-production-2026-09-17/runtime-r30/restored-film02/result.json)。

## 直接说明这次要交付什么

只需要剧本时，可以说：“写一部约40秒的都市短片剧本，先做到完整剧本。”需要完整视频时，说明时长、画幅、内容、声音与字幕，以及希望Agent自主决定的范围。例如：

> 做一部35–40秒的温暖都市短片，主要在一个小店发生，两位虚构成年人物，用具体行动化解误会。台词、镜头和常规制作由你决定。使用H3生成视频，完成剪辑、声音、中文字幕并导出16:9完整成片。交付时给出文件位置和仍存在的问题。

必须保持的角色、产品外观、准确台词或现有片段，直接说明或选中对应内容。不必先人工填完所有素材、规划和检查表；Agent可以按当前资料逐步制作。需要在某处停下时，明确说“先写完剧本给我看”等具体边界，其余常规决定可以交给Agent。

“剧本、镜头、成片”展示同一项目的当前内容，完整保存的场次会自动出现，生成中的草稿单独标识。“项目资产”集中查看人物、场景、道具、声音及文件，不需要在多个页面重复保存同一素材。制作助手与任务记录显示实际动作、结果或具体阻塞；长时间等待本身不是重复提交的理由。

## 修改时说明位置和要保留的内容

在对应场次或镜头使用“请Agent修改”，或在聊天中写清镜号及采用位置。通常可以复用旧素材的可用范围或局部剪辑；确实需要新画面时再补拍。例如：

> 只替换第3镜当前采用的画面，让父亲先看女儿，轻轻笑一下，再低头。保留这处的成片时长、已有声音、中文字幕和其余镜头，完成后重新导出。

这类“只换画面”会产生新的视频候选，采用时保留所绑定位置的已有声音。候选可能长于最终使用范围，例如本轮生成4秒候选、实际只采用约2.54秒；无需把其他镜头也换掉。一个镜头或同一素材被使用多次时，指出具体哪一处。已经变化的源素材、采用窗口或对白映射仍需重新核对，不能把旧请求直接套到新位置。

该路径用于已有正式分镜和实际采用画面的局部修改。旧项目中含糊的多镜归属不会被自动猜测补齐；若单镜页面与全片中的采用位置不一致，应先让Agent核对已有使用关系，避免把已存在画面误当作需要新增。本轮真实画面替换、其他18片段和9条字幕保持、完整混音输入相同及原生导出范围见[局部保留记录](../output/daily-production-2026-09-17/rework/actual-after-check/result.json)与[播放观察](../output/daily-production-2026-09-17/rework/native-film-preview.json)。这仍不是主观听感或表演质量的保证。

手工调整单镜头时，进入该镜的局部剪辑，时间从0秒计；保存同步成片，取消不写入。分镜正文通过“编辑分镜 / 保存分镜 / 取消”修改。Agent应保护已生效的人工改动和无关内容；遇到当前内容已变的提示，先读取相关位置再继续，不用重新发送整片目标覆盖它。

## 中途暂停、补充要求和恢复

需要停下时使用制作助手的“暂停”。已开始的操作会在合适边界结束并落盘，等界面显示暂停后再正常退出应用。重开后若要恢复原目标，再沿原任务点“继续”，不要重新发送一遍完整要求代替恢复。本轮在H3已提交时真实验证过暂停、同包重开和继续：原任务/已提交身份保持，没有重复生成；远端生成仍可能在本地暂停期间继续。[实际生命周期](../output/daily-production-2026-09-17/rework/restart-check/native-lifecycle.json)

补充要求时说明新的目标或范围，Agent会结合原任务处理。遇到连接或供应商错误，先查看具体状态：短暂语言连接失败可沿原任务退避恢复，已保存媒体继续复用；提交结果不确定时不能仅因等待较久就再次生成。本轮第二片的一次语言瞬断和一次Leader截断后完整新计划重试已实际恢复，另一次Worker输出上限失败的修复在暂停后随r30加载，尚未用该故障实跑。缺失的连接失败用量继续保留未知，不保证所有错误都能自动恢复。本次用户结束观察后任务保持paused，已受理的远端生成仍可能继续，提交未知也不会因本地暂停而自动结案。

导入项目后媒体会按新目录恢复，历史视频/声音观察记录可能未带入；“来源无法唯一判断”与“没有声音覆盖”不同，也不等于已听审通过。若本地声音检查提示资源缺失，应处理所报具体环境问题并沿原任务继续，不能把资源就绪当作内容检查成功。

## 查看实际交付与成本

在“成片”查看完整时间线、播放和导出，关注台词是否完整、关键动作是否可读，以及接点和人物/道具状态是否影响故事理解。导出结果提供完整视频及字幕；检查记录应写明实际观察范围，抽帧、字幕对齐和音频测量不能替代听感与精确口型判断。必要的内容问题继续处理，不只为消除微小手势或几何未知反复重做。

制作记录保留真实用量、等待、失败和恢复。新片≤45分钟、首次H3≤15分钟等是本轮原工程观察目标，**没有作为产品硬上限或自动停止规则**；首片五项目标未达，第二片暂停时调用、输入、首H3和墙钟四项未达，因未交片无法评价收尾时长。第二片已报用量的官方价参考小计约$300.82，另有语言及H3费用UNKNOWN；这不是完整账单，缺失usage不填零。[暂停费用与限制](../output/daily-production-2026-09-17/02/paused-observation-cost.md)

用户将金额先视为模型定价与选择因素，本轮不切换Astra/xhigh、不继续追加效率实验，也不等待第二片自主交片。以[本轮记录](research/2026-09-17-daily-production-goal.md)中的实际版本和观察范围判断可用性；用户认可稳定性与结束观察，不改写原效率未达、暂停状态和未验收内容。
