# 镜头编辑、剪辑与时长

更新：2026-09-09。用户本轮要求覆盖此前“镜头入口只定位整集时间线”的方案。三个主入口继续保留：剧本、镜头、成片。本文记录本轮产品决定；实现与验收分别记录，不能把决定写成已交付。

## 一个镜头的两种内容

分镜设计是拍摄意图，包括叙事目的、景别、画面、动作、运镜、表演、对白引用、声音、逐时段描述和具体图片引用。视频与剪辑是已经得到的结果。两者属于同一个镜号，但修改一方不伪造另一方已经变化。

镜头页默认只读。标题处始终有“编辑分镜”和“让 Agent 修改”；进入编辑后显示“保存分镜 / 取消”和未保存提示，所有设计字段集中编辑。只有点击保存才更新正式分镜及后续生成输入。取消放弃本次草稿，显示最新已保存内容；切换镜头或页面保留草稿，回来继续。保存失败保留输入。Agent 同时更新内容时不直接覆盖人工草稿。

@ 引用在只读态仍可悬停和键盘聚焦预览实际图片；编辑态才可增加、更换、解除或调整用途。逐段对白引用正式剧本行，可选择该段使用哪些台词；台词正文在剧本中改，或让 Agent 同步修改正式剧本与相关分镜，不能在镜头里另存一份不同的对白。

编辑态提供“保存并交给 Agent”，避免把未保存文字误当成正式输入。右侧对话始终说明存在未保存草稿时 Agent 读取已保存内容；其他镜头仍可并行制作。

## 三种时长

| 名称 | 含义 | 修改位置 |
| --- | --- | --- |
| 设计时长 | 分镜准备表达多久；逐时段描述使用这个镜头内的时间 | 编辑分镜 |
| 素材时长 | 分配给本镜头的可用视频范围；生成源文件可能同时包含其他镜头 | 视频信息；替换或重新生成视频 |
| 成片采用 | 当前剪辑实际占用的时间，考虑裁切、拆分、速度等 | 剪辑镜头或剪辑成片 |

例如设计 5 秒、可用素材 5.4 秒，裁掉开头 0.4 秒与结尾 1 秒后采用 4 秒。分镜仍保留设计 5 秒；成片减少 1 秒还是更多，取决于修改前真正采用的长度，而不是设计值。界面显示两者，不把正常差异当错误，也不把修改设计时长当视频变速。

调整设计总时长可按比例移动描述的分段边界；分段边界也能单独编辑。这里的 `[1–3s]` 始终表示分镜镜头内的设计时间。它既不是整集播放位置，也不是共享源文件里的裁切入点。成片时间与源素材入点只在剪辑中显示。

## 单镜头剪辑

点击“剪辑镜头”进入仅含当前镜头画面、关联原声、本镜字幕与本镜补充内容的 LTX 编辑视图，播放头从 0 秒开始。其他镜头不在此时间线上出现。复用 LTX 播放、裁切、拆分、音量、字幕与轨道组件。

“保存镜头剪辑”将本镜头改动写回本集当前时间线；“取消”放弃此次未保存剪辑。保存后镜头预览、采用时长、成片时间线同步更新。普通连续组接中，下游镜头及随镜声音、字幕按本次长度差移动，避免留洞或重叠。原始媒体与分镜设计时长保持不变。

成片入口显示完整多轨时间线，可以调整跨镜头顺序、整片音乐和跨镜字幕。已有整片配乐不在单镜头视图中被悄悄裁掉或变速；长度变化可能需要重新处理节拍，提示实际影响。音乐主导作品的节拍调整交由用户或 Agent 根据语义决定。

两处使用同一个已保存剪辑文档；局部编辑通过明确的镜头范围合并，不能用一个过滤后的全片副本覆盖其他镜头。重复使用、交错组接等情况下需明确对应的使用位置，不能默默修改无关使用。

成片页默认连续预览当前保存的剪辑，单镜头保存后立即可见。最近导出的 MP4 是一次真实文件结果，不会自动改写；需要新文件时重新导出，旧文件下载明确标注“下载上次导出”。

## 还没有视频时

正常路径是完整剧本 → 完整文字分镜 → 补齐所需资产 → 视频 → 剪辑与成片，Agent 可根据用户目标采用其他合理顺序。分镜先于视频存在；不依赖生成成功才展示镜头。

没有视频时，以完整分镜正文为主要内容，保留镜号、设计时长、分段、对白、@ 参考和状态；视频区域是简短的“待生成”占位，提供“生成视频 / 导入视频”。“剪辑镜头”在素材可用后启用，采用时长显示“尚未采用”，不拿设计时长冒充真实视频长度。成片同时区分计划总时长、可用镜头数和实际剪辑长度；未生成处不伪装成完成的视频。

## Agent 的操作语义

| 用户要求 | 正式写入与结果 |
| --- | --- |
| 只生成完整分镜 | 完整分镜逐条出现，完成分镜后结束本次任务 |
| 将第 3 镜改为近景 | 修改该镜头的分镜设计；已有视频提示可按新设计更新 |
| 把第 3 镜重新拍成近景 | 修改设计并按现有授权生成相关视频，保留可兼容的人工剪辑 |
| 去掉第 3 镜开头半秒 | 读取当前镜头剪辑，修改真实素材裁切，保存并同步成片，不重新生成视频 |
| 第 3 镜的这句台词改一下 | 修改对应剧本正文与分镜对白引用，按本次目标决定是否更新声音和视频 |
| 生成完整视频 | 按目标继续所需制作、剪辑和导出；定向修改不自动取消原来的完整视频目标 |

这些是语义示例，不是关键词路由规则。Agent 与人工调用同一套内容与剪辑保存接口。Trace 继续保留实际工具调用、作用镜头、变更、模型和上下文用量，不增加内容版本界面。

生成组的最后一镜可以使用模型实际返回的剩余片尾，即使它超出了原设计时长。当前可用素材时长、局部预览和保存范围保持一致；其他镜头仍以实际分配的来源范围为界。延长采用时长会同步关联原声并顺移后续内容，分镜设计时长不随剪辑改变。
