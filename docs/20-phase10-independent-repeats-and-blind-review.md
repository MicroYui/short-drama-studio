# Phase 10：独立重复、连续性收敛与三版盲评

## 目标与结果

Phase 10 将同一锁定《别相信我》制片包再独立执行两次真人 `AUTO_DRAFT`，不要求用户在资产、分镜、候选、QA 或时间线中途操作。Run 2 和 Run 3 都已自动到达 9 镜可播放时间线、音频 QA 和 1080×1920 导出；加上 Phase 8 Run 1，三版匿名成片已组成盲评包。

E007 的工程前置条件已完成：三次运行全部导出，其中 Run 1 和 Run 3 的入选 Take 没有高严重度问题；Run 2 有一个明确保留的高严重度道具外观偏差。2026-08-20，用户选择不填写数值 CSV，改为直接提交三版完整观看后的汇总结论；本轮产品验收据此完成，并选择 C 版作为当前最终版。该结论是用户定性验收，不等同于原协议中的三人评分数据。

## 独立重复入口

新增 `POST /api/short-drama/projects/{source_project_id}/autonomous-repeats`。它复用来源项目已批准的前期制片包，但新建并重新执行：

- 镜头关键帧与其语义审片；
- MiniMax-H3 768P 任务与候选 Take；
- 镜内、镜间视频观察与逐候选 QA；
- Director Agent 有界修复、自动选 Take 与失效传播；
- `TimelineManifest`、音频检查、字幕与最终导出。

复用的是锁定剧本、`ProjectBible`、分镜方案和已批准核心资产媒体，不复用原项目的关键帧、H3 视频、Take、QA 结论、时间线或导出。复制时对领域 ID 进行精确重映射，并深拷贝可修改的 `ShotPlan`，避免新运行的 Director 修复反向污染来源项目。

## 连续性与直接成片

连续性不是导出前才补的一次检查，而是从规划到拼接一直流动的结构化状态：

1. `ShotPlan.continuity` 保存人物位置、眼线、道具状态和动作起止；`ReferencePlan` 表达当前镜头真正需要的身份、场景、道具、动作节拍和交互锚点。
2. 资产 Agent 根据实际分镜按需建立角色转面、场景 Master/Reverse/交互视图、道具产品/持握/状态图和镜头关键帧，不要求每个角色固定生成全套三视图。
3. `VideoInspector` 对每个候选做适应性抽帧，同时生成镜内时序接触表和上一镜尾部→当前镜头开头的边界表。长镜头同样使用全时域均匀覆盖加高变化帧，不只检查首尾帧。
4. QA 发现问题后，Director Agent 会比较重生成、换关键帧、拆镜和换覆盖机位；修复历史作为下一轮输入，避免在输入没有实质变化时重复无效策略。这些仍是 Agent 建议，用户可忽略。
5. 每镜选出当前可用 Take 后，系统直接生成 `TimelineManifest`，按镜头顺序写入入选媒体、时长、原生音轨和锁定字幕 cue；导出器统一转为 1080×1920、30fps，自动拼接并输出无字幕和烧字幕版。

因此，当前三次真实运行都不需要人工导出单镜后再另开剪辑软件拼片。时间线是自动运行的产物，后续仍可在编辑器中替换 Take 或局部返工。

## 通用收敛修复

Run 2 / Run 3 暴露并修复的是通用编排问题，没有增加门、区域穿越或某个样片的专用字段：

- Director 输入增加已应用的修复历史，并明确提醒尝试实质不同的方案。
- `CHANGE_CAMERA` 会使下一轮进入可控关键帧路线，而不是仅改一句 prompt 后继续同一路线。
- 当某个精细角度参考不可用时，可使用已批准核心身份/场景/道具图作为粗粒度回退，同时保留缺口告警。
- 关键帧只携带路线真正选中的参考，并根据镜头构图选择场景、人物或道具为主编辑画布。
- Director JSON 如果误把只读的 `shot_id` / `bindings` / 验证字段复制到可更新的 `reference_plan` 中，解析器会只剔除这些已知只读包装字段，其他未知字段仍会报错。
- 修复轮数耗尽时，系统可为技术通过、分数足够且只剩非结构性偏差的最佳 Take 打上有界最佳可用标记。QA 仍保持 `REJECTED` 和 `hard_gate_passed=false`，问题不被洗掉；身份、接触、朝向或核心空间断裂不可豁免。
- 视频审片的严重度现在按对成片故事的影响校准。核心叙事动作、时序状态、身份、接触、朝向或空间连续性明确断裂才是 `HIGH`；核心信息已成立时，次要环境动作、构图偏好或润色细节未完成应为 `MEDIUM`。
- 同一 Take 重新审片时，最新语义问题集会替换已过时的视觉问题，而不是无限累积；Worker 已确认的 `TECHNICAL_MEDIA` 问题仍会保留。

用户完整观看 A/B/C 后选择直接提交结论，不再填写 `e007-blind-review-form.csv`：

这轮结论满足“至少 2/3 没有明确严重失败”的产品判断：A 的首镜接缝记为空间连续性缺陷但未被用户判为整片严重失败，B 的声音来源错误记为严重语义失败，C 通过。由于没有三名独立评审、1–5 分数和继续观看意愿字段，不能再计算原协议的核心项中位数或宣称完成了三人匿名评分 benchmark。

B 暴露的是通用的 `声音来源语义` 缺口，而不是录音笔专用问题。现有自动音频 QA 能核对“说了什么”和跨镜声线，却没有联合画面判断“是谁/什么设备在发声、画面中的人物是否应当开口”。该缺口继续记录，但用户已明确 Phase 11 只支持可选角色参考音频输入，不新增声音 QA；若未来重启联合判断，也不应为录音笔增加专用领域字段。

## 结论边界

- 三次都能生成和直接拼接成片，证明从锁定剧本到导出的自动闭环已可运行；不等于已证明对任意剧本都稳定。
- Run 1–3 是在 Phase 8–10 持续修复通用编排缺口期间完成，不是一个完全不变构建下的统计稳定性实验。它们可用于本轮 E007 成片盲评与系统收敛验收；跨剧本、同版本稳定率仍为 `UNKNOWN`。
- 自动音频 QA 可检查对白、时间和声线相对一致性，但本轮证明它尚不能单独判断声音来源语义；这是当前已知边界，本阶段不继续扩展声音 QA。
- C 是本轮用户定性验收选出的当前最终版。该选择完成产品迭代闭环，但不补造未收集的三人评分与数值统计。
