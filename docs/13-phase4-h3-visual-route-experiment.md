# Phase 4：批准资产下的 H3 视觉路线实验

## 目标与边界

本阶段使用用户已批准的林夏、周衡、雨夜便利店和红色旧录音笔 `AssetVersion`，验证 MiniMax-H3 在真人都市短剧中的视觉路线。结论按镜头类型记录，不预设整片只能使用一种路线。

本阶段固定：

- 视频模型只使用 `MiniMax-H3`；
- 所有真实视频固定 `768P`；
- 使用《别相信我》的锁定剧本、镜头时长、人物、场景和道具状态；
- Direct、Frame 与 Reference 使用相同主提示语义；
- Frame 与 Reference 不在同一次请求中混用；
- 声音只记录诊断结果，不在本阶段改变音频路线；
- 技术冒烟不作为质量通过证据，也不能进入正式时间线。

## 执行顺序与样本量

1. 免费编译 Direct、Frame、Reference 的合法请求，确认批准版本绑定、分辨率、时长和互斥规则；
2. 每个计划条件先生成 1 条可行性筛选样本，只排除接口不成立、输入明显不适配或稳定复现的严重错误，不据此宣布路线胜出；
3. 保留的正式实验条件各生成 5 个独立样本，匿名打乱后审片；
4. 可能成为默认路线的条件扩展到至少 10 个有效样本；
5. 结果接近或波动时每次增加 5 个，最多 20 个，仍不稳定则保持 `UNKNOWN`；
6. 选出按镜头类型的路线后再扩展完整八镜，不在代表镜头阶段直接生成整片。

## 判定规则

严重失败至少包括：

- 人物身份混淆、坏脸坏手、人物融合或服装变化；
- 店招乱码或凭空出现可读品牌；
- 红色录音笔变成对讲机、出现天线、外形或颜色漂移；
- 镜头 3 不是周衡右手、镜头 5 不在柜台中央、镜头 8 不是林夏左手；
- 门和收银台关系明显颠倒、动作方向错误或无动机越轴；
- 明显坏帧、错误画幅、错误时长、缺失必要媒体或动作无法完成。

图像增强路线只有在动态画质不低于 Direct，并在身份、空间、道具、构图、镜头指令遵循或稳定率中至少一项明显更强时才通过。默认路线至少需要 10 个有效样本、严重失败率不高于 20%、综合硬门槛通过率不低于 70%；最终入选成片的 Take 必须逐条通过全部硬门槛。

盲评沿用项目统一 1–5 分表。本阶段重点查看角色一致、场景/道具连续、动作流畅、摄影与构图，并单独记录声音、台词和口型诊断；音频路线在后续独立实验中决定。

## GPT-5.6-sol 提示实验

视觉输入路线确定前不改变提示编译器，避免把提示和视觉条件混成同一个变量。路线方向明确后，使用镜头 2 和镜头 5，分别比较当前确定性编译提示与 GPT-5.6-sol 编译提示；两组保持同一 H3 路线、批准素材、时长和对白。只有指令遵循或画面质量提高且不改写锁定事实时才采用语言模型编译结果。
