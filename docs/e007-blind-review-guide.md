# E007 三版成片盲评说明

## 评审材料

盲评包内含 `version-A-subtitled.mp4`、`version-B-subtitled.mp4` 和 `version-C-subtitled.mp4`。三个文件来自同一锁定剧本和前期设定的三次独立 `AUTO_DRAFT`，文件名不显示运行次序或修复路线。

## 操作方法

1. 每位评审先以正常速度完整播放三版，第一遍不暂停、不逐帧；三人的播放起始顺序分别使用 `A-B-C`、`B-C-A`、`C-A-B`。
2. 在 `e007-blind-review-form.csv` 中填写对应的 `R1`、`R2` 或 `R3` 三行。十个质量维度使用 1–5 的整数，5 为最好。
3. `want_to_continue` 填 `YES` 或 `NO`。`severe_failure` 填 `YES` 或 `NO`；如为 `YES`，在 `severe_failure_note` 记录具体时间点和问题。
4. 第一遍评分后可以复看和暂停，用于确认台词、口型、连续性或坏帧；不要打开盲评包外的内部映射文件，直到三人都提交。

## 评分维度

- `story_clarity`：故事与反转是否容易理解。
- `character_consistency`：人物身份、脸、发型、服装和表演是否连贯。
- `scene_prop_continuity`：场景、空间、录音笔等道具是否连贯。
- `action_editing`：动作、人物朝向、运镜和剪辑是否流畅。
- `cinematography`：景别、构图、光线和视觉质感。
- `dialogue_accuracy`：五句锁定台词是否正确。
- `voice_continuity`：同一角色跨镜声线是否一致。
- `lip_sync`：说话人与口型是否匹配。
- `audio_quality`：人声、环境声、节奏和整体听感。
- `subtitles`：字幕内容、时间和可读性。

## 严重失败与通过线

严重失败包括明显换人、对白含义错误或缺失、说话人错位、持续明显口型错误、关键道具/空间状态断裂、明显坏帧或缺音轨。局部景别稍松、轻微外观漂移或个人审美偏好不自动等同于严重失败。

E007 要求三次运行全部自动到可播放并导出，至少 2/3 完整草稿无严重失败；最终批准片的核心维度中位数不低于 4/5，且至少 2/3 评审愿意继续看。
